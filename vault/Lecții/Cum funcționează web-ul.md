# Cum funcționează web-ul

[[Tehnologia informației și a comunicațiilor (TIC) (clasa a XI-a)|Tehnologia informației și a comunicațiilor (TIC)]] · [[Clasa a XI-a]] · lecția 1 din 9

**Capitolul:** Web: structură și publicare — semestrul 1

## Rezumat

Web-ul funcționează pe modelul client–server: browserul (clientul) cere o resursă, serverul o trimite. Cererea folosește protocolul HTTP sau HTTPS; adresa (URL) cuprinde protocolul, numele de domeniu, calea și, eventual, parametrii. Numele de domeniu este tradus în adresă IP de sistemul DNS. Găzduirea (hosting) este serviciul care păstrează fișierele site-ului pe un server accesibil permanent. Site-urile pot fi statice (fișiere livrate ca atare) sau dinamice (paginile se generează la cerere, din baze de date). Sistemele de gestionare a conținutului permit administrarea unui site fără scrierea codului. Un site bine făcut este rapid, accesibil, adaptat ecranelor mici și corect indexat de motoarele de căutare.

## Idei-cheie

- Web-ul funcționează pe modelul client–server, prin HTTP/HTTPS.
- URL-ul cuprinde protocolul, domeniul, calea și parametrii.
- Site-uri statice (fișiere livrate ca atare) și dinamice (generate din baze de date).
- Un site bun este rapid, accesibil, adaptat mobilului și indexabil.
