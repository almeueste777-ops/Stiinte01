# Legături, imagini și tabele

[[Tehnologia informației și a comunicațiilor (TIC) (clasa a XI-a)|Tehnologia informației și a comunicațiilor (TIC)]] · [[Clasa a XI-a]] · lecția 12 din 16

**Capitolul:** HTML și CSS de bază — semestrul 1

## Rezumat

Legăturile (hyperlink-urile) conectează paginile web și se creează cu eticheta a, prin atributul href, care indică destinația (o altă pagină, o secțiune, o adresă de e-mail). Imaginile se inserează cu eticheta img și atributele src (calea) și alt (descrierea); textul alternativ alt e esențial pentru accesibilitate și pentru cazul în care imaginea nu se încarcă. Tabelele organizează date pe rânduri și coloane: elementul table conține rânduri (tr), iar fiecare rând conține celule de antet (th) sau de date (td). Structura semantică contează: un tabel e pentru date tabelare, nu pentru așezarea paginii. Căile pot fi absolute (adresa completă) sau relative (față de pagina curentă). O pagină bine construită folosește legături clare, imagini cu text alternativ și tabele doar pentru date.

## Idei-cheie

- Legăturile se fac cu eticheta a; href dă destinația.
- Imaginile: img cu src și alt; alt = text alternativ pentru accesibilitate.
- Tabelele: table, rânduri tr, celule th/td.
- Căile pot fi absolute sau relative.
