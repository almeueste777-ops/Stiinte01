# Rețele de calculatoare, internet și servicii web

[[Tehnologia informației și a comunicațiilor (TIC) (clasa a IX-a)|Tehnologia informației și a comunicațiilor (TIC)]] · [[Clasa a IX-a]] · lecția 3 din 16

**Capitolul:** Calculatorul și sistemul de operare — semestrul 1

## Rezumat

O rețea de calculatoare este un ansamblu de sisteme autonome interconectate prin medii fizice (cablu torsadat UTP/STP, fibră optică) sau unde radio (Wi-Fi, Bluetooth, rețele mobile 4G/5G) în scopul comunicării și partajării de resurse hardware, software și date. După aria de acoperire geografică, rețelele se clasifică în: LAN (Local Area Network — o sală de clasă, o clădire), MAN (Metropolitan Area Network — un oraș) și WAN (Wide Area Network — o țară sau o rețea globală). Internetul este rețeaua mondială a rețelelor, funcționând pe baza suitei de protocoale standard TCP/IP. Protocolul IP (Internet Protocol) gestionează adresarea logică a dispozitivelor (adrese IPv4 de 32 biți de tipul 192.168.1.1 sau IPv6 de 128 biți). Protocolul TCP (Transmission Control Protocol) garantează transmiterea corectă, ordonată și fără pierderi a pachetelor de date. Serviciul DNS (Domain Name System) acționează ca o carte de telefon a internetului, convertind numele ușor de reținut (ex: www.edu.ro) în adrese IP numerice înțelese de routere. Serviciile majore ale internetului includ: World Wide Web (WWW — pagini hipertext transferate prin protocoalele HTTP/HTTPS), poșta electronică (E-mail prin SMTP, IMAP, POP3), transferul de fișiere (FTP/SFTP) și stocarea în cloud (Google Drive, OneDrive). Pentru navigare sigură pe web, protocolul HTTPS folosește criptare SSL/TLS, garantând că datele trimise (parole, formulare) nu pot fi interceptate pe traseu.

## Idei-cheie

- Rețelele se clasifică după întindere în LAN (locale), MAN (metropolitane) și WAN (globale).
- Adresa IP identifică unic un echipament conectat la o rețea TCP/IP.
- Serviciul DNS traduce adresele URL alfanumerice în adrese IP numerice.
- HTTPS criptează traficul web, prevenind interceptarea datelor confidențiale.
