# Obișnuințe trecute: used to, would, be/get used to

[[Limba modernă 1 (Engleză) (clasa a X-a)|Limba modernă 1 (Engleză)]] · [[Clasa a X-a]] · lecția 11 din 18

**Capitolul:** Verb și timp (aprofundare) — semestrul 1

## Rezumat

„Used to + infinitiv" exprimă obișnuințe și stări din trecut care nu mai sunt valabile: „I used to play football", „There used to be a cinema here". Negativul și interogativul folosesc „did": „I didn't use to like coffee", „Did you use to live here?". „Would + infinitiv" exprimă și el acțiuni repetate în trecut (obișnuințe), dar nu și stări: „Every summer we would go to the seaside" este corect, însă pentru o stare („I would have a bike") este greșit — acolo se folosește „used to". „Would" cu sens de obișnuință apare mai ales în narațiuni și descrieri nostalgice. „Be used to" și „get used to" au un sens complet diferit: a fi, respectiv a deveni obișnuit cu ceva; sunt urmate de un substantiv sau de forma cu -ing: „I'm used to getting up early", „She is getting used to the new school". Deosebirea față de „used to + infinitiv" este o capcană clasică: „I used to smoke" (obișnuință trecută) față de „I'm used to smoking" (sunt obișnuit cu asta).

## Idei-cheie

- „Used to + infinitiv" exprimă obișnuințe și stări trecute care nu mai sunt valabile.
- „Would + infinitiv" exprimă acțiuni repetate în trecut, dar nu și stări.
- „Be/get used to" înseamnă a fi/a deveni obișnuit cu ceva, urmat de substantiv sau -ing.
- „I used to smoke" (obișnuință trecută) diferă de „I'm used to smoking" (sunt obișnuit).
