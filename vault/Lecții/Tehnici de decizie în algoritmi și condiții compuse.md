# Tehnici de decizie în algoritmi și condiții compuse

[[Tehnologia informației și a comunicațiilor (TIC) (clasa a X-a)|Tehnologia informației și a comunicațiilor (TIC)]] · [[Clasa a X-a]] · lecția 13 din 16

**Capitolul:** Tehnici algoritmice și colecții de date (vectori) — semestrul 2

## Rezumat

Deciziile logice complexe din algoritmi necesită evaluarea mai multor condiții simultan, utilizând operatorii logici booleeni: 1. Operatorul logic ȘI (AND): expresia compusă (C1 AND C2) este ADEVĂRATĂ dacă și numai dacă ambele condiții componente sunt simultan adevărate. De exemplu, pentru ca un elev să primească bursă de merit, trebuie să aibă (media >= 9.50) ȘI (nota_purtare == 10). Dacă una dintre ele este falsă, întreaga expresie devine falsă. 2. Operatorul logic SAU (OR): expresia (C1 OR C2) este ADEVĂRATĂ dacă cel puțin una dintre condiții este adevărată. De exemplu, un candidat este admis la profil real dacă (optiunea == "Mate-Info") SAU (optiunea == "Stiinte"). 3. Operatorul logic NEGAȚIE (NOT): inversează valoarea logică de adevăr: NOT(ADEVĂRAT) devine FALS, iar NOT(FALS) devine ADEVĂRAT. Structura de decizie multiplă (instrucțiunea CASE / SWITCH): Atunci când o variabilă poate lua mai multe valori discrete distincte (ex: cifra corespunzătoare zilei săptămânii de la 1 la 7), folosirea zecilor de IF-uri devine ineficientă. Structura de selecție multiplă evaluează variabila și execută direct ramura corespondentă valorii găsite: în_cazul_în_care (zi) este 1: scrie "Luni" 2: scrie "Marți" ... altfel: scrie "Zi invalidă" sfârșit_caz

## Idei-cheie

- Operatorul AND cere îndeplinirea simultană a tuturor condițiilor logice.
- Operatorul OR este satisfăcut dacă cel puțin o condiție este adevărată.
- Operatorul NOT inversează starea logică a expresiei evaluate.
- Instrucțiunea CASE / SWITCH gestionează elegant alegerile dintr-o listă fixă de variante.
