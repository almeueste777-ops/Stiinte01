# Lucru mecanic, putere, randament

[[Fizică (clasa a IX-a)|Fizică]] · [[Clasa a IX-a]] · lecția 5 din 18

**Capitolul:** Lucru mecanic și energie — semestrul 1

## Rezumat

Lucrul mecanic se efectuează când o forță deplasează punctul ei de aplicație; el este produsul dintre forță, deplasare și cosinusul unghiului dintre ele. Dacă forța e perpendiculară pe deplasare, lucrul mecanic este nul — de aceea forța centripetă nu efectuează lucru mecanic. Unitatea de măsură este joulul: un joule este lucrul efectuat de o forță de un newton pe o deplasare de un metru în direcția forței. Puterea este lucrul mecanic efectuat în unitatea de timp și se măsoară în wați; un cal-putere este aproximativ 736 de wați. Randamentul unei mașini este raportul dintre lucrul mecanic util și lucrul mecanic consumat, exprimat procentual; el este întotdeauna subunitar, pentru că o parte din energie se pierde prin frecare și încălzire. Nicio mașină reală nu are randament 100%, iar perpetuum mobile este imposibil.

## Idei-cheie

- Lucrul mecanic este produsul dintre forță, deplasare și cosinusul unghiului dintre ele.
- O forță perpendiculară pe deplasare nu efectuează lucru mecanic.
- Puterea este lucrul mecanic în unitatea de timp, măsurată în wați.
- Randamentul e mereu subunitar: o parte din energie se pierde prin frecare.
