# Țesuturile muscular și nervos

[[Biologie (clasa a IX-a)|Biologie]] · [[Clasa a IX-a]] · lecția 15 din 18

**Capitolul:** Histologie — semestrul 2

## Rezumat

Țesutul muscular este format din celule alungite, contractile, care transformă energia chimică în mișcare. Există trei tipuri. Mușchiul striat scheletic, cu aspect vărgat la microscop, se prinde de oase și este voluntar, adică se contractă la comandă. Mușchiul neted, fără striații, se află în pereții organelor interne (stomac, intestine, vase) și este involuntar. Mușchiul cardiac, striat dar involuntar, formează inima și se contractă ritmic, neobosit, toată viața. Țesutul nervos este specializat în recepționarea, prelucrarea și transmiterea informației. Este format din neuroni, celulele funcționale, și din celule gliale, care îi susțin și îi hrănesc. Neuronul are un corp celular, prelungiri scurte și ramificate (dendritele), care primesc informația, și o prelungire lungă (axonul), care o transmite mai departe. Impulsul nervos este un semnal electric care circulă de-a lungul neuronului; între doi neuroni, transmiterea se face chimic, la nivelul sinapsei, prin substanțe numite neurotransmițători. Aceste două țesuturi, muscular și nervos, colaborează strâns: sistemul nervos comandă, iar mușchii execută mișcarea, într-o coordonare permanentă.

## Idei-cheie

- Mușchiul striat scheletic este voluntar; cel neted și cel cardiac sunt involuntare.
- Mușchiul cardiac este striat, dar se contractă involuntar și ritmic.
- Neuronul are corp celular, dendrite (primesc) și axon (transmite).
- Între neuroni, transmiterea se face chimic, la sinapsă.
