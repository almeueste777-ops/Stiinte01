# Funcția putere și funcția radical

[[Matematică (clasa a X-a)|Matematică]] · [[Clasa a X-a]] · lecția 10 din 18

**Capitolul:** Funcția putere, radical și trigonometrie — semestrul 1

## Rezumat

Funcția putere are forma f de x egal cu x la puterea n, cu n număr natural nenul. Comportarea ei depinde de paritatea exponentului. Pentru exponent par, funcția este pară: graficul este simetric față de axa verticală, valorile sunt nenegative, iar forma seamănă cu a parabolei. Pentru exponent impar, funcția este impară: graficul este simetric față de origine, iar funcția ia atât valori pozitive, cât și negative.
Funcția radical de ordin n este inversa funcției putere: ea „desface" ridicarea la putere. Ordinul radicalului îi impune domeniul. Radicalul de ordin par este definit numai pentru numere nenegative, pentru că nicio putere pară a unui număr real nu poate fi negativă; radicalul de ordin impar este definit pentru orice număr real. Pe domeniul numerelor nenegative, funcția radical este strict crescătoare, iar graficul ei este simetricul graficului funcției putere față de prima bisectoare, ca la orice pereche de funcții inverse.

## Idei-cheie

- Funcția putere cu exponent par este pară; cu exponent impar, impară.
- Funcția radical este inversa funcției putere.
- Radicalul de ordin par este definit doar pentru numere nenegative.
- Radicalul de ordin impar este definit pentru orice număr real.
