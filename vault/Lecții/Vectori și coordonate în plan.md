# Vectori și coordonate în plan

[[Matematică (clasa a X-a)|Matematică]] · [[Clasa a X-a]] · lecția 16 din 18

**Capitolul:** Geometrie analitică — semestrul 2

## Rezumat

În reperul cartezian, un vector se descrie prin componentele lui pe cele două axe. Vectorul determinat de două puncte are drept componente diferențele coordonatelor: din coordonatele punctului final se scad coordonatele punctului inițial. Modulul vectorului, adică lungimea lui, se calculează cu teorema lui Pitagora, ca rădăcina din suma pătratelor componentelor.
Adunarea vectorilor se face pe componente, iar înmulțirea cu un scalar înmulțește fiecare componentă. Produsul scalar a doi vectori dați prin componente este suma produselor componentelor corespunzătoare; el este legat și de modulele vectorilor și de cosinusul unghiului dintre ei. De aici rezultă criteriul de perpendicularitate: doi vectori nenuli sunt perpendiculari exact atunci când produsul lor scalar este zero. Calculul vectorial în coordonate permite rezolvarea numerică a problemelor de geometrie: distanțe, unghiuri, arii, coliniaritate.

## Idei-cheie

- Componentele vectorului dintre două puncte sunt diferențele coordonatelor.
- Modulul vectorului este rădăcina din suma pătratelor componentelor.
- Produsul scalar este suma produselor componentelor corespunzătoare.
- Doi vectori nenuli sunt perpendiculari dacă produsul lor scalar este zero.
