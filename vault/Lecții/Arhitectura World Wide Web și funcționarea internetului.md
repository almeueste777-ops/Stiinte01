# Arhitectura World Wide Web și funcționarea internetului

[[Tehnologia informației și a comunicațiilor (TIC) (clasa a XI-a)|Tehnologia informației și a comunicațiilor (TIC)]] · [[Clasa a XI-a]] · lecția 1 din 16

**Capitolul:** Web: structură, protocoale și publicare — semestrul 1

## Rezumat

World Wide Web (WWW) este un sistem global de documente hipertext interconectate, accesibile prin intermediul rețelei internet. Arhitectura fundamentală a web-ului este de tip Client-Server: 1. Clientul (User Agent): este aplicația software rulată pe calculatorul sau telefonul utilizatorului (browserul web: Google Chrome, Mozilla Firefox, Microsoft Edge, Safari). Rolul clientului este de a trimite cereri (HTTP Requests) către servere, de a primi datele de răspuns (HTTP Responses) și de a le parsa și afișa vizual pe ecran. 2. Serverul Web: este un calculator de mare putere conectat permanent la internet, care rulează software specializat (Apache, Nginx, Microsoft IIS). Serverul stochează fișierele site-ului (pagini HTML, fișiere CSS, scripturi, imagini) și le transmite clienților la cerere. Comunicarea se bazează pe protocolul HTTP (Hypertext Transfer Protocol) sau varianta sa criptată și securizată HTTPS (portul standard 443). O adresă web completă poartă numele de URL (Uniform Resource Locator) și are structura: protocol://domeniu:port/cale/fisier?parametri#ancora Exemplu: https://liceulioncreangatgneamt.ro/admitere/rezultate.html Un rol esențial îl are procesul de găzduire web (Web Hosting) și înregistrarea numelor de domenii prin registratori oficiali (ex: RoTLD pentru domeniile naționale românești .ro).

## Idei-cheie

- Arhitectura web este client-server: browserul cere resurse, iar serverul web le livrează.
- Protocolul HTTPS folosește criptare TLS/SSL pentru a securiza transmiterea datelor pe internet.
- URL-ul este adresa globală unică a unei resurse pe web (protocol, domeniu, cale, fișier).
- Serverele web populare care deservesc pagini sunt Nginx și Apache.
