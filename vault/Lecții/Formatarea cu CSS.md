# Formatarea cu CSS

[[Tehnologia informației și a comunicațiilor (TIC) (clasa a XI-a)|Tehnologia informației și a comunicațiilor (TIC)]] · [[Clasa a XI-a]] · lecția 11 din 16

**Capitolul:** HTML și CSS de bază — semestrul 1

## Rezumat

CSS (Cascading Style Sheets) descrie aspectul paginilor: culori, fonturi, dimensiuni, spațiere, așezare. O regulă CSS are un selector (ce element vizează) și un bloc de declarații (proprietate: valoare), de exemplu p { color: blue; font-size: 16px; }. Stilurile pot fi puse în trei feluri: în linie (atributul style), interne (în elementul style) sau externe (fișier .css legat) — varianta externă e cea recomandată, fiindcă separă conținutul de prezentare. Selectorii de bază: după element (p), după clasă (.nume), după id (#nume). Proprietăți frecvente: color, background, font-family, margin, padding, border. „Cascada” din nume înseamnă că regulile se aplică în ordine și după specificitate. Separarea HTML–CSS face site-ul mai ușor de întreținut.

## Idei-cheie

- CSS descrie aspectul: culori, fonturi, spațiere, așezare.
- O regulă = selector + declarații (proprietate: valoare).
- Stiluri: în linie, interne, externe (externe = recomandat).
- Selectori: element (p), clasă (.nume), id (#nume).
