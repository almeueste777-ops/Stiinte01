# Funcția exponențială

[[Matematică (clasa a X-a)|Matematică]] · [[Clasa a X-a]] · lecția 1 din 9

**Capitolul:** Funcții și ecuații — semestrul 1

## Rezumat

Funcția exponențială are forma f(x) = a la puterea x, cu baza a strict pozitivă și diferită de 1. Domeniul ei este mulțimea numerelor reale, iar imaginea, intervalul numerelor strict pozitive: valoarea nu atinge niciodată zero. Graficul trece întotdeauna prin punctul de coordonate (0, 1), pentru că orice bază la puterea zero dă 1, și are axa Ox ca asimptotă orizontală. Funcția este strict crescătoare dacă baza este mai mare decât 1 și strict descrescătoare dacă baza este între 0 și 1. Fiind strict monotonă, este injectivă, ceea ce permite rezolvarea ecuațiilor exponențiale prin egalarea exponenților atunci când bazele sunt egale. Creșterea exponențială depășește orice creștere polinomială și modelează fenomene reale: dobânda compusă, înmulțirea bacteriilor, dezintegrarea radioactivă (cu bază subunitară), răspândirea unei epidemii în faza inițială.

## Idei-cheie

- Baza funcției exponențiale este strict pozitivă și diferită de 1.
- Graficul trece prin (0, 1) și are axa Ox ca asimptotă.
- Este crescătoare pentru bază supraunitară, descrescătoare pentru bază subunitară.
- Modelează dobânda compusă, creșterea populațiilor și dezintegrarea radioactivă.
