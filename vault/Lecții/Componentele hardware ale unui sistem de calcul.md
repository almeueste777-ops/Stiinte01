# Componentele hardware ale unui sistem de calcul

[[Tehnologia informației și a comunicațiilor (TIC) (clasa a IX-a)|Tehnologia informației și a comunicațiilor (TIC)]] · [[Clasa a IX-a]] · lecția 1 din 16

**Capitolul:** Calculatorul și sistemul de operare — semestrul 1

## Rezumat

Un sistem de calcul este un ansamblu integrat de componente hardware (fizice, electronice și mecanice) și software (programe și date). Arhitectura clasică a unui calculator (modelul Von Neumann) cuprinde: Unitatea Centrală de Prelucrare (CPU - procesorul), memoria internă (RAM și ROM), memoria externă (discuri SSD, HDD, memorii flash USB), dispozitivele periferice de intrare (tastatură, mouse, scaner, microfon, cameră web), perifericele de ieșire (monitor, imprimantă, boxe) și dispozitivele de intrare-ieșire (placă de rețea, touchscreen, modem). Procesorul (CPU) reprezintă „creierul” calculatorului și coordonează execuția instrucțiunilor. Performanța sa este determinată de frecvența de tact (măsurată în GHz), numărul de nuclee (cores) și memoria cache internă (L1, L2, L3). Memoria RAM (Random Access Memory) este memorie de lucru rapidă, dar volatilă — tot conținutul ei se pierde la oprirea alimentării cu energie. Memoria ROM (Read-Only Memory) este nevolatilă și păstrează firmware-ul de bază (BIOS/UEFI) necesar inițializării hardware-ului la pornire. Unitățile SSD (Solid State Drive) bazate pe memorie flash au înlocuit vechile hard disk-uri mecanice (HDD), oferind viteze de citire și scriere de 5-30 de ori mai mari și rezistență la șocuri.

## Idei-cheie

- Hardware = componente fizice; Software = totalitatea programelor ce rulează pe hardware.
- Memoria RAM este volatilă (datele nesalvate se pierd); SSD/HDD asigură stocarea permanentă.
- BIOS/UEFI este stocat în cipul ROM și inițiază pornirea calculatorului (POST - Power-On Self Test).
- Performanța generală depinde de echilibrul dintre procesor, cantitatea de memorie RAM și viteza SSD-ului.
