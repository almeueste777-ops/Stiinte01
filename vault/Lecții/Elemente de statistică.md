# Elemente de statistică

[[Matematică (clasa a X-a)|Matematică]] · [[Clasa a X-a]] · lecția 6 din 18

**Capitolul:** Combinatorică și probabilități — semestrul 1

## Rezumat

Statistica descriptivă organizează datele: populația este mulțimea studiată, eșantionul este partea observată, iar caracteristica este însușirea măsurată. Datele se prezintă prin tabele de frecvențe și grafice: diagrama cu bare pentru date calitative, histograma pentru date grupate, diagrama circulară pentru structuri, poligonul frecvențelor pentru evoluții. Indicatorii de tendință centrală sunt media aritmetică (sensibilă la valorile extreme), mediana (valoarea din mijloc, robustă la extreme) și modul (valoarea cea mai frecventă). Alegerea între ele contează: la venituri, media poate fi trasă în sus de câteva valori foarte mari, iar mediana descrie mai fidel situația tipică. Indicatorii de împrăștiere — amplitudinea, abaterea medie și abaterea standard — arată cât de omogene sunt datele. Un eșantion nereprezentativ invalidează orice concluzie, oricât de corect ar fi calculul.

## Idei-cheie

- Populația este mulțimea studiată; eșantionul, partea observată.
- Media este sensibilă la valorile extreme; mediana este robustă.
- Modul este valoarea cu frecvența cea mai mare.
- Abaterea standard măsoară împrăștierea datelor față de medie.
