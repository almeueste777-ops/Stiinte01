# Structuri fundamentale de control și instrucțiuni repetitive

[[Tehnologia informației și a comunicațiilor (TIC) (clasa a X-a)|Tehnologia informației și a comunicațiilor (TIC)]] · [[Clasa a X-a]] · lecția 8 din 16

**Capitolul:** Algoritmi și gândire computațională — semestrul 1

## Rezumat

Teorema structurală Böhm-Jacopini demonstrează că orice algoritm, oricât de complex, poate fi construit combinând exclusiv trei structuri fundamentale de control: 1. Structura secvențială (liniară): instrucțiunile se execută una după alta, în ordinea exactă în care au fost scrise, fără sărituri sau ramificări. 2. Structura alternativă (de decizie / selecție): evaluează o condiție logică; dacă este ADEVĂRATĂ, se execută o ramură de comenzi (Then), altfel se execută o altă ramură (Else) sau se continuă algoritmul: dacă (condiție) atunci instrucțiuni_1 altfel instrucțiuni_2 sfârșit_dacă 3. Structurile repetitive (bucle / cicluri): permit executarea repetată a unui bloc de comenzi: • Cu număr cunoscut de pași (bucla PENTRU / FOR): se folosește un contor ce parcurge un interval de valori: pentru i = 1 până la n execută instrucțiuni sfârșit_pentru • Cu test inițial și număr necunoscut de pași (bucla CÂT TIMP / WHILE): condiția este verificată înainte de fiecare iterație; dacă de la început este falsă, blocul nu se execută nici măcar o dată: cât_timp (condiție) execută instrucțiuni sfârșit_cât_timp • Cu test final (bucla REPETĂ ... PÂNĂ CÂND / DO-WHILE): blocul se execută cel puțin o dată, iar condiția se testează la final.

## Idei-cheie

- Orice algoritm este alcătuit din structuri secvențiale, alternative și repetitive.
- Structura alternativă (IF-THEN-ELSE) ramifică execuția în funcție de o condiție logică.
- Bucla FOR este utilizată atunci când numărul de iterații este cunoscut dinainte.
- Bucla WHILE testează condiția înainte de execuție și se poate executa de zero ori.
