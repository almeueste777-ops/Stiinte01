# Progresii aritmetice și geometrice

[[Matematică aplicată în științele sociale (clasa a XII-a)|Matematică aplicată în științele sociale]] · [[Clasa a XII-a]] · lecția 10 din 18

**Capitolul:** Progresii și matematici financiare — semestrul 1

## Rezumat

Multe fenomene evoluează după tipare regulate, descrise de progresii. O progresie aritmetică este un șir în care fiecare termen se obține din precedentul adunând o valoare constantă, numită rație: 3, 7, 11, 15, … are rația 4. Termenul de rang n este a_n = a_1 + (n − 1)·r, iar suma primilor n termeni este n·(a_1 + a_n)/2 — media primului și ultimului termen, înmulțită cu numărul lor. O progresie geometrică este un șir în care fiecare termen se obține din precedentul înmulțind cu o valoare constantă, numită rație: 2, 6, 18, 54, … are rația 3. Termenul de rang n este a_n = a_1·q^(n−1). Diferența de comportament este esențială: progresia aritmetică crește constant (liniar), pe când cea geometrică crește sau scade tot mai repede — exponențial. Pe termen lung, o progresie geometrică cu rația supraunitară depășește orice progresie aritmetică. Legătura cu finanțele este directă. Dobânda simplă, calculată mereu la suma inițială, produce o progresie aritmetică; dobânda compusă, calculată la suma acumulată, produce o progresie geometrică. Aceasta explică de ce, în timp, diferența dintre ele devine uriașă și de ce economisirea timpurie contează atât de mult. Progresiile geometrice descriu și creșterea populației, răspândirea unei informații sau deprecierea unui bun cu un procent fix pe an.

## Idei-cheie

- Progresie aritmetică: se adună o rație constantă; creștere liniară.
- Progresie geometrică: se înmulțește cu o rație constantă; creștere exponențială.
- Termen general: aritmetică a_n = a_1 + (n−1)·r; geometrică a_n = a_1·q^(n−1).
- Dobânda simplă e o progresie aritmetică; dobânda compusă, una geometrică.
