# Structura paginii web moderne: conținut, prezentare și comportament

[[Tehnologia informației și a comunicațiilor (TIC) (clasa a XI-a)|Tehnologia informației și a comunicațiilor (TIC)]] · [[Clasa a XI-a]] · lecția 2 din 16

**Capitolul:** Web: structură, protocoale și publicare — semestrul 1

## Rezumat

Dezvoltarea web modernă respectă principiul strict al separării responsabilităților (Separation of Concerns), divizând o pagină în trei straturi tehnologice independente: 1. Stratul de Structură și Conținut — limbajul HTML (HyperText Markup Language): Definește „ce” conține pagina: titluri, paragrafe de text, imagini, tabele, liste, formulare și legături hipertext. HTML nu trebuie să dicteze culori sau așezare în pagină, ci doar sensul logic al elementelor (semantică web: `<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`). 2. Stratul de Prezentare și Stil — limbajul CSS (Cascading Style Sheets): Definește „cum” arată elementele din pagină: culori, fundaluri, familii de fonturi, dimensiuni, margini, borduri, așezare pe coloane (CSS Flexbox, CSS Grid) și adaptare la ecrane de telefon mobil (Responsive Design prin Media Queries). 3. Stratul de Comportament și Interactivitate — limbajul JavaScript (JS): Definește „ce face” pagina: validează formularele înainte de trimitere, afișează ferestre modale, preia date asincron fără reîncărcarea paginii (AJAX / Fetch API) și reacționează la acțiunile utilizatorului (clicuri de mouse, tastare, derulare). Această decuplare permite, de exemplu, schimbarea completă a temei grafice a unui site întreg prin modificarea unui singur fișier CSS, fără a atinge conținutul scris în paginile HTML.

## Idei-cheie

- Dezvoltarea web separă strict conținutul (HTML), prezentarea vizuală (CSS) și logica (JavaScript).
- HTML5 pune accent pe elementele semantice (`<header>`, `<nav>`, `<main>`, `<footer>`).
- CSS controlează paleta de culori, tipografia și așezarea elementelor pe ecrane diferite.
- JavaScript transformă paginile statice în aplicații web interactive și dinamice.
