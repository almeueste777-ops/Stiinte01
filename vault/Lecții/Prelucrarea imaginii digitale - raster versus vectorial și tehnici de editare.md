# Prelucrarea imaginii digitale: raster versus vectorial și tehnici de editare

[[Tehnologia informației și a comunicațiilor (TIC) (clasa a X-a)|Tehnologia informației și a comunicațiilor (TIC)]] · [[Clasa a X-a]] · lecția 6 din 16

**Capitolul:** Baze de date și structurarea informației — semestrul 1

## Rezumat

Imaginile digitale sunt clasificate în două mari categorii tehnologice: 1. Grafica Raster (Bitmap): imaginea este o matrice dreptunghiulară de pixeli colorați. La mărirea imaginii (zoom-in), pixelii devin vizibili, iar imaginea își pierde claritatea, apărând pixelată și zimțată. Exemple de formate: JPEG, PNG, GIF, BMP, TIFF. Este formatul ideal pentru fotografii reale din natură, bogate în detalii fine și nuanțe cromatice continue. 2. Grafica Vectorială: imaginea este definită matematic prin primitive geometrice (puncte, linii, curbe Bézier, poligoane și umpleri). Marele avantaj este scalabilitatea infinită: imaginea poate fi mărită la dimensiunea unei clădiri fără nicio pierdere de claritate sau rezoluție. Exemple de formate: SVG (Standard Vector Graphics pentru web), AI, CDR, EPS. Este formatul standard pentru logouri, icoane, sigle și diagrame tehnice. Operațiile esențiale în programele de editare grafică (Photoshop, GIMP, Inkscape): • Straturi (Layers) — permit izolarea elementelor grafice pe foi transparente suprapuse, editabile independent; • Decupare (Crop) — eliminarea marginilor inutile și reîncadrarea compoziției; • Rezoluție și redimensionare — măsurată în DPI (Dots Per Inch) sau PPI (Pixeli Per Inch); pentru web sunt suficienți 72-96 DPI, în timp ce pentru tipar profesional se cer 300 DPI; • Corecții de culoare — ajustarea luminozității (Brightness), contrastului și a saturației (Saturation).

## Idei-cheie

- Grafica raster este alcătuită din pixeli și se distorsionează la zoom; grafica vectorială este scalabilă infinit.
- Formatul SVG este standardul de grafică vectorială utilizat nativ în paginile web.
- Straturile (Layers) permit modificarea unui element fără a afecta restul imaginii.
- Pentru tipărirea de calitate la imprimantă este necesară o rezoluție de cel puțin 300 DPI.
