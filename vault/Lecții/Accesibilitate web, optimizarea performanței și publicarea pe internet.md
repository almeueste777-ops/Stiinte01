# Accesibilitate web, optimizarea performanței și publicarea pe internet

[[Tehnologia informației și a comunicațiilor (TIC) (clasa a XI-a)|Tehnologia informației și a comunicațiilor (TIC)]] · [[Clasa a XI-a]] · lecția 3 din 16

**Capitolul:** Web: structură, protocoale și publicare — semestrul 1

## Rezumat

Un site web profesional trebuie să poată fi accesat în condiții optime de către toți utilizatorii, indiferent de dispozitivul folosit sau de eventualele dizabilități: 1. Accesibilitatea Web (standardele W3C / WAI-WCAG): • Asigurarea contrastului adecvat între text și fundal (raport minim de contrast 4.5:1 pentru text normal); • Prezența obligatorie a atributului `alt` pe toate imaginile (`<img src="poza.jpg" alt="Descriere clară">`), permițând persoanelor nevăzătoare ce utilizează software de tip cititor de ecran (Screen Reader) să înțeleagă conținutul vizual; • Navigare completă din tastatură (fără a depinde exclusiv de mouse, folosind tasta Tab); • Ierarhie clară de titluri (un singur `<h1>` per pagină, urmat ordonat de `<h2>` și `<h3>`). 2. Optimizarea performanței (Web Performance): Viteza de încărcare a unei pagini influențează experiența utilizatorului și poziționarea în căutările Google (SEO): • Comprimarea imaginilor și utilizarea formatelor moderne ușoare (WebP, SVG); • Minificarea fișierelor CSS și JavaScript (eliminarea spațiilor și a comentariilor pentru micșorarea dimensiunii fișierelor descărcate); • Folosirea memoriei cache a browserului pentru resursele statice. 3. Publicarea pe internet: Încărcarea fișierelor locale pe serverul de hosting se realizează prin protocoale de transfer securizat de fișiere (SFTP / FTPS) folosind aplicații dedicate (ex: FileZilla, WinSCP) sau prin fluxuri moderne de integrare continuă bazate pe Git și GitHub Pages.

## Idei-cheie

- Accesibilitatea web asigură că persoanele cu dizabilități pot naviga eficient pe site.
- Atributul `alt` este obligatoriu pe tagurile `<img>` pentru cititoarele de ecran.
- Optimizarea imaginilor (format WebP) și minificarea codului reduc dramatic timpul de încărcare.
- Publicarea paginilor pe server se realizează prin transfer securizat SFTP sau platforme moderne de hosting.
