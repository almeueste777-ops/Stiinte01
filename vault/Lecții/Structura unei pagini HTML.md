# Structura unei pagini HTML

[[Tehnologia informației și a comunicațiilor (TIC) (clasa a XI-a)|Tehnologia informației și a comunicațiilor (TIC)]] · [[Clasa a XI-a]] · lecția 10 din 16

**Capitolul:** HTML și CSS de bază — semestrul 1

## Rezumat

HTML (HyperText Markup Language) este limbajul de marcare care descrie structura unei pagini web. O pagină e alcătuită din elemente, delimitate de etichete: de deschidere (<p>) și de închidere (</p>). Structura minimă cuprinde declarația <!DOCTYPE html>, elementul rădăcină <html>, secțiunea <head> (metadate: titlu, codare, legături) și <body> (conținutul vizibil). Elementele importante: titluri (<h1>–<h6>), paragrafe (<p>), liste (<ul>, <ol>, <li>), legături (<a>), imagini (<img>). HTML descrie SENSUL conținutului (structura), nu aspectul lui, care e treaba CSS-ului. Etichetele pot avea atribute (href, src, alt) care le precizează comportamentul. O structură corectă și semantică face pagina accesibilă și ușor de indexat de motoarele de căutare.

## Idei-cheie

- HTML descrie structura paginii prin elemente și etichete.
- Structura minimă: <!DOCTYPE html>, <html>, <head>, <body>.
- Elemente: titluri, paragrafe, liste, legături, imagini.
- HTML dă structura (sensul), CSS dă aspectul.
