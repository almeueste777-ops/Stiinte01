# Trigonometrie în triunghiul dreptunghic

[[Matematică (clasa a IX-a)|Matematică]] · [[Clasa a IX-a]] · lecția 7 din 9

**Capitolul:** Trigonometrie și vectori — semestrul 2

## Rezumat

În triunghiul dreptunghic, sinusul unui unghi ascuțit este raportul dintre cateta opusă și ipotenuză, cosinusul este raportul dintre cateta alăturată și ipotenuză, iar tangenta este raportul dintre cateta opusă și cea alăturată. Aceste rapoarte depind doar de unghi, nu de mărimea triunghiului, pentru că triunghiurile dreptunghice cu același unghi ascuțit sunt asemenea. Valorile remarcabile se memorează: pentru 30 de grade sinusul este 1/2, pentru 45 de grade sinusul și cosinusul sunt egale cu rădăcină din 2 supra 2, pentru 60 de grade sinusul este rădăcină din 3 supra 2. Identitatea fundamentală spune că suma pătratelor sinusului și cosinusului aceluiași unghi este 1. Teorema lui Pitagora leagă laturile: pătratul ipotenuzei este suma pătratelor catetelor. Aplicațiile practice sunt directe: măsurarea înălțimilor inaccesibile, panta unui drum, calculul distanțelor prin triangulație.

## Idei-cheie

- Sinus = catetă opusă supra ipotenuză; cosinus = catetă alăturată supra ipotenuză.
- Rapoartele depind doar de unghi, nu de mărimea triunghiului.
- Identitatea fundamentală: sin²x + cos²x = 1.
- Teorema lui Pitagora leagă ipotenuza de catete.
