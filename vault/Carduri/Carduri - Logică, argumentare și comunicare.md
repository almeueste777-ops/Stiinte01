# Carduri — Logică, argumentare și comunicare

6 carduri pentru [[Logică, argumentare și comunicare]]. Formatul `întrebare::răspuns` este cel folosit de pluginul *Spaced Repetition*; fără plugin rămân simple linii de recapitulare.

#flashcards/logica-argumentare-si-comunicare

Ce este sfera unei noțiuni?::Totalitatea obiectelor la care se aplică noțiunea (extensiunea).

Enunță legea raportului invers.::Cu cât conținutul unei noțiuni este mai bogat, cu atât sfera ei este mai restrânsă (și invers).

Ce tip de propoziție este „Unii oameni nu sunt onești”?::O — particular negativă.

Ce raport există între A și O în pătratul logic?::Contradicție: una adevărată implică cealaltă falsă și invers.

Câți termeni are un silogism?::Trei: major, minor și mediu.

Ce este sofismul ad hominem?::Respingerea unei teze prin atacarea persoanei care o susține, nu a argumentelor ei.
