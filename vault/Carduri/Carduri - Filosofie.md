# Carduri — Filosofie

7 carduri pentru [[Filosofie]]. Formatul `întrebare::răspuns` este cel folosit de pluginul *Spaced Repetition*; fără plugin rămân simple linii de recapitulare.

#flashcards/filosofie

Cine a formulat imperativul categoric?::Immanuel Kant.

Ce înseamnă „existența precede esența”?::Teza lui Sartre: omul nu are o natură prestabilită, ci se definește prin propriile alegeri.

Ce susține empirismul?::Că întreaga cunoaștere provine din experiența sensibilă; mintea este la naștere tabula rasa.

Care este principiul utilității?::Este morală acțiunea care produce cea mai mare fericire pentru cel mai mare număr de oameni.

Ce este starea naturală la Hobbes?::Războiul tuturor împotriva tuturor, în absența unei puteri comune.

Ce studiază ontologia?::Existența ca existență: ce există și în ce mod.

Ce este „voința generală” la Rousseau?::Voința corpului politic orientată spre binele comun, sursa suveranității legitime.
