# Test — Sociologie

3 întrebări din [[Sociologie]]. Răspunsurile sunt ascunse: apasă pe săgeata callout-ului ca să le vezi.

### 1. Familia este un exemplu de grup:

- a. secundar
- b. primar
- c. formal
- d. de referință negativă

> [!success]- Răspuns
> **b. primar**
> 
> Relații directe, afective și durabile — grup primar.

### 2. Sistemul de caste este:

- a. deschis
- b. închis
- c. meritocratic
- d. temporar

> [!success]- Răspuns
> **b. închis**
> 
> Poziția este atribuită la naștere și nu poate fi schimbată.

### 3. „A trata faptele sociale ca lucruri” este regula lui:

- a. Weber
- b. Durkheim
- c. Comte
- d. Marx

> [!success]- Răspuns
> **b. Durkheim**
> 
> Regulă centrală din „Regulile metodei sociologice”.
