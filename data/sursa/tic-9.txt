## 1 | tic9-c1 | Calculatorul și sistemul de operare
### tic9-01 | Componentele unui sistem de calcul
Un sistem de calcul are componente hardware (fizice) și software (programe). Hardware-ul cuprinde unitatea centrală de prelucrare (procesorul, care execută instrucțiunile), memoria internă — RAM, volatilă, care păstrează datele în lucru, și ROM —, memoria externă (hard disk, SSD, memorii flash, discuri optice), dispozitivele de intrare (tastatură, mouse, scaner, microfon, cameră) și de ieșire (monitor, imprimantă, difuzoare).
Performanța depinde de frecvența și numărul de nuclee ale procesorului, de cantitatea de RAM, de tipul memoriei externe (SSD-ul este mult mai rapid decât hard diskul clasic) și de placa grafică. Unitatea de măsură a informației este bitul; un octet (byte) are 8 biți, iar multiplii uzuali sunt kilo-, mega-, giga- și terabyte.
* Hardware = componente fizice; software = programe.
* RAM este memorie volatilă; datele nesalvate se pierd la oprire.
* SSD-ul este semnificativ mai rapid decât hard diskul clasic.
* Un octet are 8 biți; multiplii sunt KB, MB, GB, TB.
= memorie volatilă :: memorie care își pierde conținutul la întreruperea alimentării
= procesor :: componenta care execută instrucțiunile programelor
@ Ce se întâmplă cu datele din RAM la oprirea calculatorului? :: Se pierd, fiindcă RAM-ul este memorie volatilă.
@ Câți biți are un octet? :: Opt.
@ Ce dispozitive sunt de intrare? :: Tastatura, mouse-ul, scanerul, microfonul, camera.
@ De ce este SSD-ul preferabil hard diskului clasic? :: Pentru că are viteză de acces mult mai mare, fără componente mecanice.
? Memoria RAM este:
+ volatilă
- permanentă
- doar pentru citire
- externă
! De aceea documentele nesalvate se pierd.
? Monitorul este un dispozitiv de:
+ ieșire
- intrare
- stocare
- prelucrare
! Tastatura este dispozitiv de intrare.
? Un gigabyte este aproximativ:
+ 1024 megabytes
- 1024 kilobytes
- 100 megabytes
- 1024 terabytes
! Multiplii cresc, uzual, din 1024 în 1024.
? Performanța unui calculator NU depinde direct de:
+ culoarea carcasei
- cantitatea de RAM
- frecvența procesorului
- tipul memoriei externe
! Componentele interne determină performanța.

### tic9-02 | Sistemul de operare și gestionarea fișierelor
Sistemul de operare este programul care gestionează resursele calculatorului și face legătura dintre utilizator, aplicații și hardware. Funcțiile lui: gestionarea proceselor, a memoriei, a fișierelor, a dispozitivelor și interfața cu utilizatorul. Exemple: Windows, macOS, Linux, Android, iOS.
Fișierul este o colecție de date identificată printr-un nume și o extensie care indică tipul (.txt, .docx, .pdf, .jpg, .mp4, .exe). Fișierele se organizează în foldere, într-o structură arborescentă. Operațiile de bază: creare, copiere, mutare, redenumire, ștergere, căutare, arhivare. Buna organizare — nume descriptive, structură logică, denumiri cu dată pentru versiuni — economisește mai mult timp decât orice altă deprindere digitală.
* Sistemul de operare gestionează procese, memorie, fișiere, dispozitive și interfața.
* Extensia indică tipul fișierului și programul care îl deschide.
* Fișierele se organizează arborescent, în foldere.
* Numele descriptive și structura logică economisesc timp real.
= extensie de fișier :: sufixul din numele fișierului, care indică tipul de conținut
= structură arborescentă :: organizare ierarhică a folderelor, cu ramificații succesive
@ Ce face un sistem de operare? :: Gestionează resursele calculatorului și mediază între utilizator, aplicații și hardware.
@ Ce indică extensia unui fișier? :: Tipul de conținut și programul asociat pentru deschidere.
@ Cum se organizează fișierele? :: Arborescent, în foldere, pe niveluri ierarhice.
@ De ce contează numele descriptive ale fișierelor? :: Pentru că fac regăsirea rapidă și evită confuziile între versiuni.
? Extensia .docx indică, de regulă:
+ un document de text formatat
- o imagine
- un fișier executabil
- o arhivă
! Extensia .jpg indică o imagine.
? Un sistem de operare NU are ca funcție:
+ redactarea documentelor
- gestionarea memoriei
- gestionarea fișierelor
- interfața cu utilizatorul
! Redactarea se face în aplicații dedicate.
? Arhivarea unui folder este utilă pentru:
+ reducerea dimensiunii și transferul mai ușor
- creșterea vitezei procesorului
- creșterea memoriei RAM
- protejarea de viruși
! Arhivele pot fi și protejate cu parolă.
? Structura arborescentă a folderelor înseamnă:
+ organizare ierarhică, cu foldere în interiorul altor foldere
- toate fișierele într-un singur loc
- ordonare alfabetică
- ordonare după dată
! Ea permite regăsirea rapidă.

### tic9-03 | Rețele, internet și servicii web
O rețea de calculatoare leagă dispozitive pentru a partaja date și resurse. După întindere: LAN (locală), MAN (metropolitană), WAN (extinsă). Internetul este rețeaua globală care leagă rețele, funcționând pe baza protocoalelor TCP/IP. Fiecare dispozitiv are o adresă IP; sistemul DNS traduce numele de domenii în adrese IP.
Serviciile principale: web-ul (paginile accesate prin HTTP/HTTPS, cu HTTPS criptând comunicația), poșta electronică, transferul de fișiere, mesageria, streamingul, serviciile în cloud. Browserul este aplicația care afișează paginile web. Motorul de căutare indexează paginile și le ordonează după relevanță; folosirea eficientă presupune cuvinte-cheie precise, operatori de căutare (ghilimele pentru expresie exactă, minus pentru excludere, site: pentru un anumit domeniu) și verificarea sursei.
* Rețele: LAN, MAN, WAN; internetul funcționează pe protocoalele TCP/IP.
* DNS traduce numele de domenii în adrese IP.
* HTTPS criptează comunicația dintre browser și server.
* Căutarea eficientă folosește cuvinte precise și operatori.
= adresă IP :: identificatorul numeric al unui dispozitiv într-o rețea
= DNS :: sistemul care traduce numele de domenii în adrese IP
@ Ce este o adresă IP? :: Identificatorul numeric al unui dispozitiv într-o rețea.
@ Ce face sistemul DNS? :: Traduce numele de domenii în adrese IP.
@ Prin ce diferă HTTPS de HTTP? :: HTTPS criptează comunicația dintre browser și server.
@ Ce operatori ajută la căutarea eficientă? :: Ghilimelele pentru expresie exactă, minusul pentru excludere, site: pentru un domeniu anume.
? HTTPS se deosebește de HTTP prin:
+ criptarea comunicației
- viteza mai mare
- afișarea imaginilor
- accesul la fișiere
! Lacătul din bara de adrese indică o conexiune securizată.
? O rețea LAN este:
+ o rețea locală, într-o clădire sau într-o instituție
- rețeaua globală
- o rețea metropolitană
- o rețea de telefonie
! WAN desemnează rețelele extinse.
? Căutarea unei expresii exacte se face folosind:
+ ghilimelele
- semnul plus
- semnul întrebării
- asteriscul
! Minusul exclude un termen din rezultate.
? Browserul este:
+ aplicația care afișează paginile web
- motorul de căutare
- serverul care găzduiește site-ul
- protocolul de comunicație
! Motorul de căutare este un serviciu accesat prin browser.

## 2 | tic9-c2 | Editare de text și prezentări
### tic9-04 | Procesorul de text: formatare și structură
Un procesor de text permite redactarea, formatarea și tipărirea documentelor. Formatarea la nivel de caracter: font, dimensiune, stil, culoare, indici. La nivel de paragraf: aliniere, indentare, spațiere, spațiu înainte și după, liste. La nivel de pagină: margini, orientare, dimensiune, antet și subsol, numerotare.
Regula profesională este să nu formatezi manual, ci prin stiluri: aplicarea stilului „Titlu 1” pentru capitole și „Titlu 2” pentru subcapitole permite generarea automată a cuprinsului, navigarea rapidă și modificarea unitară a aspectului. Alte instrumente utile: verificarea ortografică, căutare și înlocuire, note de subsol, referințe, comentarii, urmărirea modificărilor, îmbinarea corespondenței.
* Formatarea se face la nivel de caracter, paragraf și pagină.
* Folosirea stilurilor permite cuprins automat și modificări unitare.
* Instrumente utile: căutare-înlocuire, note de subsol, comentarii, urmărirea modificărilor.
* Formatarea manuală repetată este sursa cea mai frecventă de documente inconsecvente.
= stil (în procesorul de text) :: set predefinit de formatări aplicabil unitar unui tip de conținut
= cuprins automat :: listă de titluri generată de program pe baza stilurilor aplicate
@ De ce se folosesc stilurile într-un document? :: Pentru cuprins automat, navigare rapidă și modificarea unitară a formatării.
@ Ce se formatează la nivel de paragraf? :: Alinierea, indentarea, spațierea și listele.
@ Ce este îmbinarea corespondenței? :: Procedeul de a genera documente personalizate dintr-un șablon și o listă de date.
@ Care este cel mai frecvent defect al documentelor formatate manual? :: Inconsecvența aspectului între secțiuni.
? Cuprinsul automat se poate genera dacă:
+ titlurile au stiluri aplicate
- documentul are numerotare
- textul este aliniat
- se folosesc tabele
! Programul citește ierarhia stilurilor.
? Indentarea este o formatare la nivel de:
+ paragraf
- caracter
- pagină
- document
! Fontul este formatare la nivel de caracter.
? Urmărirea modificărilor este utilă pentru:
+ lucrul în colaborare, cu vizualizarea schimbărilor
- reducerea dimensiunii fișierului
- protejarea cu parolă
- tipărirea rapidă
! Fiecare modificare poate fi acceptată sau respinsă.
? Formatarea manuală repetată a titlurilor:
+ produce inconsecvențe și îngreunează modificările
- este mai rapidă
- permite cuprins automat
- este recomandată
! Stilurile rezolvă ambele probleme.

### tic9-05 | Prezentări electronice
O prezentare electronică susține un discurs, nu îl înlocuiește. Principiile de bază: o idee pe slide, text minim (cuvinte-cheie, nu paragrafe), contrast suficient între text și fundal, font lizibil de la distanță, imagini relevante și de calitate, consecvență vizuală prin folosirea unui șablon.
Greșelile frecvente: slide-uri încărcate cu text pe care vorbitorul le citește, animații excesive, culori care reduc lizibilitatea, grafice fără etichete, prea multe slide-uri pentru timpul disponibil. Regula practică: aproximativ un slide la un minut și jumătate de vorbire. Instrumentele utile: modul de vizualizare cu note pentru vorbitor, tranzițiile simple, verificarea prezentării pe ecranul real înainte de susținere.
* Prezentarea susține discursul; nu îl înlocuiește.
* O idee pe slide, text minim, contrast bun, font lizibil, consecvență vizuală.
* Regula practică: circa un slide la un minut și jumătate.
* Se verifică prezentarea pe ecranul real înainte de susținere.
= șablon de prezentare :: set predefinit de culori, fonturi și așezări, aplicat unitar tuturor slide-urilor
= note pentru vorbitor :: text vizibil doar prezentatorului, care îl ghidează în timpul expunerii
@ Care este principiul de bază al unui slide bun? :: O idee pe slide, cu text minim.
@ Care este regula practică pentru numărul de slide-uri? :: Aproximativ un slide la un minut și jumătate de vorbire.
@ Ce sunt notele pentru vorbitor? :: Text vizibil doar prezentatorului, care îl ghidează în expunere.
@ Care este greșeala cea mai frecventă într-o prezentare? :: Slide-uri încărcate cu text, citite cu voce tare.
? Un slide bun conține:
+ o idee, exprimată prin cuvinte-cheie
- un paragraf complet
- toate detaliile expunerii
- cel puțin trei imagini
! Textul detaliat aparține discursului, nu slide-ului.
? Pentru o prezentare de 15 minute sunt potrivite, orientativ:
+ circa 10 slide-uri
- 30 de slide-uri
- 3 slide-uri
- 50 de slide-uri
! Regula este circa un slide la un minut și jumătate.
? Folosirea unui șablon asigură:
+ consecvența vizuală a prezentării
- reducerea dimensiunii fișierului
- animații automate
- corectarea greșelilor
! Consecvența ajută înțelegerea și profesionalismul.
? Citirea slide-urilor cu voce tare de către prezentator:
+ face prezentarea redundantă și plictisitoare
- este recomandată
- ajută publicul
- economisește timp
! Publicul citește mai repede decât vorbește prezentatorul.

### tic9-06 | Comunicare online și colaborare
Poșta electronică rămâne instrumentul standard al comunicării formale. Un e-mail bun are: subiect clar și specific, formulă de adresare potrivită, mesaj scurt și structurat, cerere explicită, formulă de încheiere, semnătură. Câmpurile Cc (copie) și Bcc (copie ascunsă) au reguli: Bcc pentru liste mari, ca să nu expui adresele altora.
Colaborarea online permite lucrul simultan în același document, cu istoric al versiunilor, comentarii, sugestii și drepturi de acces diferențiate (vizualizare, comentare, editare). Reguli de bună practică: se acordă doar drepturile necesare, se folosesc comentarii în loc de modificări directe în textul altcuiva, se verifică cine are acces înainte de a partaja un document cu date personale. Netiquette-ul cere claritate, politețe, evitarea majusculelor (care sugerează strigăt) și răbdare în interpretarea tonului.
* E-mailul formal: subiect clar, adresare, mesaj structurat, cerere explicită, semnătură.
* Bcc protejează adresele destinatarilor în listele mari.
* Colaborarea online: istoric al versiunilor, comentarii, drepturi diferențiate.
* Se acordă doar drepturile de acces necesare.
= Bcc :: câmp de e-mail prin care destinatarii nu văd adresele celorlalți
= drepturi de acces :: nivelul de permisiune acordat unui utilizator asupra unui document partajat
@ Ce trebuie să conțină un e-mail formal? :: Subiect clar, formulă de adresare, mesaj structurat, cerere explicită, semnătură.
@ Când se folosește Bcc? :: La liste mari de destinatari, pentru a nu expune adresele lor.
@ Ce drepturi se pot acorda la partajarea unui document? :: Vizualizare, comentare sau editare.
@ De ce se evită majusculele în comunicarea online? :: Pentru că sugerează strigăt și sunt percepute ca agresive.
? Trimiterea unui e-mail către 50 de destinatari se face corect folosind:
+ Bcc
- Cc
- câmpul „Către”
- răspuns tuturor
! Astfel adresele nu sunt expuse.
? Un subiect de e-mail bun este:
+ scurt și specific pentru conținut
- lipsă, pentru a nu limita mesajul
- format din întregul mesaj
- scris cu majuscule
! El determină dacă mesajul e deschis și găsit ulterior.
? La partajarea unui document se acordă:
+ doar drepturile necesare scopului
- întotdeauna drept de editare
- acces public implicit
- drepturi de administrator
! Este principiul privilegiului minim.
? Comentariile într-un document colaborativ sunt preferabile pentru că:
+ semnalează problema fără a modifica textul altcuiva
- sunt mai rapide
- nu pot fi șterse
- se tipăresc automat
! Ele păstrează responsabilitatea autorului asupra textului.

## 2 | tic9-c3 | Siguranță și responsabilitate digitală
### tic9-07 | Securitate: parole, malware, actualizări
Securitatea digitală începe cu parolele. O parolă bună este lungă (peste 12 caractere), unică pentru fiecare serviciu și greu de ghicit; o frază de acces formată din mai multe cuvinte este mai sigură și mai ușor de reținut decât un șir scurt cu simboluri. Managerul de parole rezolvă problema unicității. Autentificarea în doi pași adaugă un al doilea factor și blochează majoritatea atacurilor bazate pe parole furate.
Programele malițioase (malware) includ viruși, viermi, troieni, ransomware (criptează datele și cere răscumpărare), spyware. Măsuri de bază: actualizarea sistemului și a aplicațiilor, program antivirus activ, atenție la atașamente și la linkuri, descărcarea aplicațiilor doar din surse oficiale, copii de siguranță regulate. Copia de siguranță este singura protecție reală împotriva ransomware-ului.
* Parolă lungă, unică, ideal o frază de acces; manager de parole pentru unicitate.
* Autentificarea în doi pași blochează majoritatea atacurilor cu parole furate.
* Malware: viruși, viermi, troieni, ransomware, spyware.
* Copia de siguranță este singura protecție reală împotriva ransomware-ului.
= autentificare în doi pași :: verificare suplimentară, printr-un al doilea factor, la conectare
= ransomware :: program malițios care criptează datele și cere răscumpărare
@ Ce face o parolă puternică? :: Lungimea, unicitatea și imprevizibilitatea; o frază de acces e ideală.
@ Ce este autentificarea în doi pași? :: Verificarea suplimentară printr-un al doilea factor, pe lângă parolă.
@ Ce este ransomware-ul? :: Un program care criptează datele și cere răscumpărare pentru deblocare.
@ Care este singura protecție reală împotriva ransomware-ului? :: Copiile de siguranță făcute regulat.
? Cea mai eficientă măsură împotriva parolelor furate este:
+ autentificarea în doi pași
- schimbarea lunară a parolei
- folosirea aceleiași parole peste tot
- notarea parolelor pe hârtie
! Al doilea factor blochează accesul chiar cu parola compromisă.
? O frază de acces formată din patru cuvinte:
+ este, de regulă, mai sigură decât o parolă scurtă cu simboluri
- este mai slabă
- este imposibil de reținut
- nu poate fi folosită
! Lungimea contează mai mult decât complexitatea aparentă.
? Actualizările de sistem sunt importante deoarece:
+ corectează vulnerabilități de securitate cunoscute
- schimbă aspectul interfeței
- eliberează spațiu
- măresc viteza procesorului
! Amânarea lor lasă breșe deschise.
? Copiile de siguranță ar trebui păstrate:
+ și într-o locație separată de calculator
- exclusiv pe același disc
- doar în memoria RAM
- doar pe desktop
! Altfel se pierd odată cu dispozitivul.

### tic9-08 | Date personale, urmă digitală și confidențialitate
Datele cu caracter personal sunt orice informații care pot identifica o persoană: nume, adresă, CNP, e-mail, fotografii, date de localizare, identificatori online. Regulamentul general privind protecția datelor (GDPR) stabilește drepturile persoanei: informare, acces, rectificare, ștergere, restricționare, portabilitate, opoziție. Prelucrarea trebuie să aibă un temei legal, iar consimțământul trebuie să fie liber, specific și informat.
Urma digitală este ansamblul informațiilor lăsate online, activ (postări, comentarii) sau pasiv (istoric, localizare, cookie-uri). Ea este greu reversibilă: ceea ce a fost publicat poate fi copiat și redistribuit. Reguli practice: verifică setările de confidențialitate, gândește înainte de a posta, nu publica date care identifică locul unde te afli în timp real, nu distribui date personale ale altora fără acordul lor, revizuiește periodic permisiunile acordate aplicațiilor.
* Datele personale identifică, direct sau indirect, o persoană.
* GDPR dă drepturi: informare, acces, rectificare, ștergere, opoziție.
* Consimțământul trebuie să fie liber, specific și informat.
* Urma digitală e greu reversibilă: ce a fost publicat poate fi copiat.
= date cu caracter personal :: orice informații care pot identifica, direct sau indirect, o persoană
= urmă digitală :: ansamblul informațiilor lăsate de o persoană în mediul online
@ Ce sunt datele cu caracter personal? :: Orice informații care pot identifica, direct sau indirect, o persoană.
@ Ce drepturi dă GDPR? :: Informare, acces, rectificare, ștergere, restricționare, portabilitate, opoziție.
@ Ce este urma digitală? :: Ansamblul informațiilor lăsate online, activ sau pasiv.
@ De ce este urma digitală greu reversibilă? :: Pentru că ceea ce a fost publicat poate fi copiat și redistribuit de oricine.
? Adresa de e-mail este:
+ o dată cu caracter personal
- o informație publică fără protecție
- un identificator anonim
- o dată tehnică nereglementată
! Ea permite identificarea persoanei.
? Consimțământul pentru prelucrarea datelor trebuie să fie:
+ liber, specific și informat
- implicit
- dat o singură dată, pentru orice scop
- acordat de altcineva
! Bifarea prealabilă a unei căsuțe nu este consimțământ valid.
? Publicarea locației în timp real:
+ crește riscurile de securitate personală
- este recomandată
- nu are consecințe
- este obligatorie în aplicații
! Ea permite localizarea fizică a persoanei.
? Dreptul la ștergerea datelor („dreptul de a fi uitat”):
+ poate fi exercitat în condițiile prevăzute de lege
- este absolut și necondiționat
- nu există
- se aplică doar minorilor
! Există și excepții, de exemplu pentru arhivare în interes public.

### tic9-09 | Etică digitală, drepturi de autor, dezinformare
Etica digitală privește comportamentul responsabil online: respectul față de ceilalți, veridicitatea informației distribuite, respectarea drepturilor de autor și a proprietății intelectuale. Plagiatul — preluarea muncii altcuiva fără atribuire — este la fel de grav în mediul digital ca pe hârtie, iar ușurința copierii nu îl face acceptabil. Licențele deschise (Creative Commons) precizează ce este permis: reutilizare, modificare, folosire comercială, cu obligația atribuirii.
Dezinformarea circulă online mai repede decât informația verificată, fiindcă algoritmii amplifică ce produce reacție. Verificarea de bază: sursa primară, autorul, data, confirmarea din surse independente, căutarea inversă a imaginilor. Cyberbullyingul — hărțuirea repetată în mediul online — are efecte reale și grave; răspunsul corect este documentarea (capturi de ecran), raportarea în platformă, informarea unui adult și, la nevoie, sesizarea autorităților, nu răspunsul în același registru.
* Plagiatul este la fel de grav în mediul digital ca pe hârtie.
* Licențele Creative Commons precizează ce reutilizare este permisă.
* Verificarea informației: sursă primară, autor, dată, confirmare independentă.
* La cyberbullying: documentează, raportează, cere ajutor; nu răspunde în același registru.
= plagiat :: preluarea muncii altcuiva fără atribuirea sursei
= Creative Commons :: sistem de licențe care precizează condițiile de reutilizare a unei opere
@ Ce este plagiatul? :: Preluarea muncii altcuiva fără atribuirea sursei.
@ Ce precizează o licență Creative Commons? :: Condițiile de reutilizare: atribuire, modificare, folosire comercială.
@ Care sunt pașii verificării unei informații? :: Sursa primară, autorul, data, confirmarea din surse independente, căutarea inversă de imagini.
@ Cum se răspunde corect la cyberbullying? :: Documentând, raportând în platformă, cerând ajutorul unui adult, nu răspunzând în același registru.
? Folosirea unei imagini găsite online, fără verificarea licenței:
+ poate încălca drepturile de autor
- este întotdeauna permisă
- este permisă în scop școlar, fără nicio condiție
- nu are consecințe legale
! Multe imagini sunt protejate; atribuirea singură nu e mereu suficientă.
? Răspunsul corect la cyberbullying include:
+ documentarea și raportarea în platformă
- răspunsul în același registru
- ștergerea contului imediat
- ignorarea completă și tăcerea
! Documentarea permite intervenția eficientă.
? Licențele Creative Commons:
+ precizează ce reutilizări sunt permise
- elimină drepturile de autor
- se aplică automat oricărei opere
- sunt valabile doar în scop comercial
! Autorul alege tipul de licență.
? Dezinformarea circulă mai repede decât informația verificată pentru că:
+ algoritmii amplifică ce produce reacție emoțională
- este mai scurtă
- provine din surse oficiale
- este verificată automat
! Reacția, nu corectitudinea, determină difuzarea.

? Memoria RAM este:
+ volatilă
- permanentă
- doar pentru citire
- externă
! Datele nesalvate se pierd la oprire.
? Un octet are:
+ 8 biți
- 16 biți
- 4 biți
- 1024 biți
! Multiplii uzuali sunt KB, MB, GB, TB.
? Monitorul este un dispozitiv de:
+ ieșire
- intrare
- stocare
- prelucrare
! Tastatura este dispozitiv de intrare.
? Extensia unui fișier indică:
+ tipul de conținut și programul asociat
- dimensiunea fișierului
- data creării
- autorul
! De exemplu, .jpg indică o imagine.
? Sistemul DNS:
+ traduce numele de domenii în adrese IP
- criptează comunicația
- stochează paginile web
- filtrează conținutul
! Fără el ar trebui memorate adrese numerice.
? HTTPS se deosebește de HTTP prin:
+ criptarea comunicației
- viteza mai mare
- accesul la imagini
- portul folosit exclusiv
! Lacătul din bara de adrese semnalează conexiunea securizată.
? Căutarea unei expresii exacte se face cu:
+ ghilimele
- semnul plus
- asterisc
- paranteze
! Minusul exclude un termen.
? Cuprinsul automat se generează pe baza:
+ stilurilor aplicate titlurilor
- numerotării paginilor
- alinierii textului
- tabelelor inserate
! De aceea stilurile sunt esențiale.
? Indentarea este o formatare la nivel de:
+ paragraf
- caracter
- pagină
- secțiune
! Fontul se aplică la nivel de caracter.
? Un slide bun conține:
+ o idee, în cuvinte-cheie
- un paragraf întreg
- toate detaliile
- minimum cinci imagini
! Detaliile aparțin discursului.
? Pentru o prezentare de 15 minute sunt potrivite, orientativ:
+ circa 10 slide-uri
- 30 de slide-uri
- 3 slide-uri
- 45 de slide-uri
! Regula este un slide la un minut și jumătate.
? Trimiterea unui e-mail către mulți destinatari se face folosind:
+ Bcc
- Cc
- „Către”
- „Răspunde tuturor”
! Astfel adresele nu sunt expuse.

- reutilizarea aceleiași parole
! Al doilea factor blochează accesul.
? Ransomware-ul:
+ criptează datele și cere răscumpărare
- șterge sistemul de operare
- fură parolele
- încetinește calculatorul
! Copiile de siguranță sunt singura protecție reală.
? Actualizările de sistem:
+ corectează vulnerabilități cunoscute
- schimbă doar interfața
- eliberează spațiu
- cresc viteza procesorului
! Amânarea lor lasă breșe deschise.
? Copiile de siguranță trebuie păstrate:
+ și într-o locație separată
- doar pe același disc
- doar pe desktop
- doar în memoria RAM
! Altfel se pierd odată cu dispozitivul.

+ orice informații care pot identifica o persoană
- doar numele și CNP-ul
- doar datele bancare
- doar fotografiile
! Inclusiv identificatorii online și datele de localizare.
? Consimțământul pentru prelucrarea datelor trebuie să fie:
+ liber, specific și informat
- implicit
- general și permanent
- acordat de terți
! Căsuțele bifate din start nu constituie consimțământ.
? Urma digitală este:
+ ansamblul informațiilor lăsate online, activ și pasiv
- doar postările publice
- doar istoricul de navigare
- doar datele din formulare
! Ea este greu reversibilă.
? Plagiatul înseamnă:
+ preluarea muncii altcuiva fără atribuire
- citarea unei surse
- parafrazarea cu trimitere
- folosirea unei imagini licențiate
! Ușurința copierii nu îl face acceptabil.
? Licențele Creative Commons:
+ precizează condițiile de reutilizare a unei opere
- elimină drepturile de autor
- se aplică automat
- interzic orice reutilizare
! Autorul alege tipul de licență.
? Răspunsul corect la cyberbullying include:
+ documentarea și raportarea
- răspunsul în același registru
- ștergerea imediată a probelor
- tăcerea completă
! Capturile de ecran permit intervenția.
? Dezinformarea circulă rapid online deoarece:
+ algoritmii amplifică ce produce reacție emoțională
- este verificată automat
- provine din surse oficiale
- este mai scurtă
! Corectitudinea nu determină difuzarea.

+ doar drepturile necesare
- întotdeauna editare
- acces public
- drepturi de administrator
