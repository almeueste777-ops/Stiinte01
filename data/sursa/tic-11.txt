## 1 | tic11-c1 | Web: structură, protocoale și publicare
### tic11-01 | Arhitectura World Wide Web și funcționarea internetului
World Wide Web (WWW) este un sistem global de documente hipertext interconectate, accesibile prin intermediul rețelei internet. Arhitectura fundamentală a web-ului este de tip Client-Server:
1. Clientul (User Agent): este aplicația software rulată pe calculatorul sau telefonul utilizatorului (browserul web: Google Chrome, Mozilla Firefox, Microsoft Edge, Safari). Rolul clientului este de a trimite cereri (HTTP Requests) către servere, de a primi datele de răspuns (HTTP Responses) și de a le parsa și afișa vizual pe ecran.
2. Serverul Web: este un calculator de mare putere conectat permanent la internet, care rulează software specializat (Apache, Nginx, Microsoft IIS). Serverul stochează fișierele site-ului (pagini HTML, fișiere CSS, scripturi, imagini) și le transmite clienților la cerere.
Comunicarea se bazează pe protocolul HTTP (Hypertext Transfer Protocol) sau varianta sa criptată și securizată HTTPS (portul standard 443). O adresă web completă poartă numele de URL (Uniform Resource Locator) și are structura:
protocol://domeniu:port/cale/fisier?parametri#ancora
Exemplu: https://liceulioncreangatgneamt.ro/admitere/rezultate.html
Un rol esențial îl are procesul de găzduire web (Web Hosting) și înregistrarea numelor de domenii prin registratori oficiali (ex: RoTLD pentru domeniile naționale românești .ro).
* Arhitectura web este client-server: browserul cere resurse, iar serverul web le livrează.
* Protocolul HTTPS folosește criptare TLS/SSL pentru a securiza transmiterea datelor pe internet.
* URL-ul este adresa globală unică a unei resurse pe web (protocol, domeniu, cale, fișier).
* Serverele web populare care deservesc pagini sunt Nginx și Apache.
= Client-Server :: model arhitectural în care clienții solicită servicii, iar serverele le furnizează
= URL :: identificatorul global și adresa unică a unei pagini sau a unui fișier pe internet
= browser web :: aplicație client care descarcă, interpretează și afișează paginile web
= găzduire web (Hosting) :: serviciul prin care un server stochează și menține accesibile fișierele unui site
@ Care este rolul browserului web în modelul client-server? :: Trimite cereri HTTP la server și interpretează codul HTML/CSS/JS pentru a-l desena pe ecran.
@ Ce diferențiază protocolul HTTPS de protocolul HTTP clasic? :: HTTPS include un nivel de securitate criptată (SSL/TLS) ce împiedică interceptarea parolelor.
@ Din ce elemente este alcătuit un URL complet? :: Protocol (https), nume de domeniu (site.ro), calea folderelor și numele fișierului căutat.
@ Ce organizație gestionează domeniile cu terminația „.ro” în România? :: RoTLD (Institutul Național de Cercetare-Dezvoltare în Informatică).

### tic11-02 | Structura paginii web moderne: conținut, prezentare și comportament
Dezvoltarea web modernă respectă principiul strict al separării responsabilităților (Separation of Concerns), divizând o pagină în trei straturi tehnologice independente:
1. Stratul de Structură și Conținut — limbajul HTML (HyperText Markup Language):
Definește „ce” conține pagina: titluri, paragrafe de text, imagini, tabele, liste, formulare și legături hipertext. HTML nu trebuie să dicteze culori sau așezare în pagină, ci doar sensul logic al elementelor (semantică web: `<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`).
2. Stratul de Prezentare și Stil — limbajul CSS (Cascading Style Sheets):
Definește „cum” arată elementele din pagină: culori, fundaluri, familii de fonturi, dimensiuni, margini, borduri, așezare pe coloane (CSS Flexbox, CSS Grid) și adaptare la ecrane de telefon mobil (Responsive Design prin Media Queries).
3. Stratul de Comportament și Interactivitate — limbajul JavaScript (JS):
Definește „ce face” pagina: validează formularele înainte de trimitere, afișează ferestre modale, preia date asincron fără reîncărcarea paginii (AJAX / Fetch API) și reacționează la acțiunile utilizatorului (clicuri de mouse, tastare, derulare).
Această decuplare permite, de exemplu, schimbarea completă a temei grafice a unui site întreg prin modificarea unui singur fișier CSS, fără a atinge conținutul scris în paginile HTML.
* Dezvoltarea web separă strict conținutul (HTML), prezentarea vizuală (CSS) și logica (JavaScript).
* HTML5 pune accent pe elementele semantice (`<header>`, `<nav>`, `<main>`, `<footer>`).
* CSS controlează paleta de culori, tipografia și așezarea elementelor pe ecrane diferite.
* JavaScript transformă paginile statice în aplicații web interactive și dinamice.
= HTML :: limbaj de marcare care structurează conținutul și semantica unei pagini web
= CSS :: limbaj de foi de stil care definește aspectul vizual și machetarea grafică a paginii
= JavaScript :: limbaj de programare care oferă dinamism și interactivitate în browser
= semantică web :: folosirea tagurilor HTML conform semnificației lor logice reale
@ Ce rol are limbajul HTML într-o pagină web? :: Definește conținutul și structura logică a informațiilor din pagină.
@ Ce tehnologie este responsabilă de culori, margini și aranjarea pe coloane a unui site? :: Limbajul CSS (Cascading Style Sheets).
@ Ce aduce limbajul JavaScript unei pagini web? :: Interactivitate, animații complexe și reacție dinamică la acțiunile utilizatorului.
@ Care este avantajul separării CSS-ului într-un fișier extern? :: Permite schimbarea aspectului întregului site dintr-un singur loc, fără a rescrie paginile.

### tic11-03 | Accesibilitate web, optimizarea performanței și publicarea pe internet
Un site web profesional trebuie să poată fi accesat în condiții optime de către toți utilizatorii, indiferent de dispozitivul folosit sau de eventualele dizabilități:
1. Accesibilitatea Web (standardele W3C / WAI-WCAG):
• Asigurarea contrastului adecvat între text și fundal (raport minim de contrast 4.5:1 pentru text normal);
• Prezența obligatorie a atributului `alt` pe toate imaginile (`<img src="poza.jpg" alt="Descriere clară">`), permițând persoanelor nevăzătoare ce utilizează software de tip cititor de ecran (Screen Reader) să înțeleagă conținutul vizual;
• Navigare completă din tastatură (fără a depinde exclusiv de mouse, folosind tasta Tab);
• Ierarhie clară de titluri (un singur `<h1>` per pagină, urmat ordonat de `<h2>` și `<h3>`).
2. Optimizarea performanței (Web Performance):
Viteza de încărcare a unei pagini influențează experiența utilizatorului și poziționarea în căutările Google (SEO):
• Comprimarea imaginilor și utilizarea formatelor moderne ușoare (WebP, SVG);
• Minificarea fișierelor CSS și JavaScript (eliminarea spațiilor și a comentariilor pentru micșorarea dimensiunii fișierelor descărcate);
• Folosirea memoriei cache a browserului pentru resursele statice.
3. Publicarea pe internet:
Încărcarea fișierelor locale pe serverul de hosting se realizează prin protocoale de transfer securizat de fișiere (SFTP / FTPS) folosind aplicații dedicate (ex: FileZilla, WinSCP) sau prin fluxuri moderne de integrare continuă bazate pe Git și GitHub Pages.
* Accesibilitatea web asigură că persoanele cu dizabilități pot naviga eficient pe site.
* Atributul `alt` este obligatoriu pe tagurile `<img>` pentru cititoarele de ecran.
* Optimizarea imaginilor (format WebP) și minificarea codului reduc dramatic timpul de încărcare.
* Publicarea paginilor pe server se realizează prin transfer securizat SFTP sau platforme moderne de hosting.
= accesibilitate (WCAG) :: principii internaționale pentru a face web-ul utilizabil de persoanele cu dizabilități
= atribut alt :: text descriptiv alternativ afișat dacă imaginea nu se încarcă sau este citită de un screen reader
= format WebP :: format modern de compresie a imaginilor pentru web, mult mai mic decât JPEG și PNG
= SFTP :: protocol securizat de transfer de fișiere între calculatorul local și serverul de internet
@ La ce folosește atributul `alt` din cadrul etichetei de imagine HTML? :: Oferă o descriere textuală a imaginii pentru persoanele nevăzătoare și dacă poza nu se poate încărca.
@ Ce este un Screen Reader? :: Un program software care citește cu voce tare textul și etichetele de pe ecran pentru nevăzători.
@ Cum influențează optimizarea imaginilor performanța unui site? :: Reduce dimensiunea fișierelor în Kilobytes, permițând încărcarea aproape instantanee a paginii.
@ Ce program este frecvent utilizat pentru a transfera fișiere prin FTP/SFTP pe un server web? :: Aplicația FileZilla (sau WinSCP).
? Atributul HTML obligatoriu pentru a oferi o descriere accesibilă unei imagini este:
+ alt
- src
- href
- font
! Atributul alt conține textul alternativ pentru accesibilitate și motoare de căutare.
? Formatul modern de imagine conceput de Google pentru a oferi compresie superioară pe web este:
+ .webp
- .exe
- .bmp clasic
- .wav
! WebP oferă imagini la o calitate similară cu JPEG, dar cu o dimensiune cu 30% mai mică.
? Protocolul criptat recomandat pentru încărcarea sigură a fișierelor pe serverul de găzduire este:
+ SFTP (SSH File Transfer Protocol)
- Telnet
- HTTP simplu
- Bluetooth
! SFTP criptează datele și parolele în timpul transferului către server.
? Pentru ca o pagină să poată fi navigată de persoane care nu pot folosi mouse-ul, interfața trebuie să suporte:
+ navigarea completă cu ajutorul tastei Tab
- doar comenzi vocale în engleză
- ecrane tactile de mari dimensiuni
- două tastaturi simultan
! Focalizarea secvențială cu Tab este pilonul accesibilității fizice pe web.

## 1 | tic11-c2 | Multimedia: sunet, imagine în mișcare și montaj digital
### tic11-04 | Prelucrarea și optimizarea sunetului digital
Sunetul este o undă mecanică analogică produsă de vibrații. Pentru a fi procesat pe calculator, semnalul captat de microfon este convertit digital prin placă de sunet (ADC - Analog-to-Digital Converter).
Parametrii esențiali ai calității audio digitale:
1. Rata de eșantionare (Sample Rate): numărul de măsurători efectuate pe secundă, exprimat în Hertz (Hz) sau KiloHertz (kHz). Standardul pentru voce este de 22.05 kHz, standardul de CD audio este de 44.1 kHz, iar cel pentru producții video profesionale este de 48 kHz.
2. Rezoluția pe eșantion (Bit Depth): numărul de biți alocați fiecărui eșantion pentru a descrie amplitudinea undei (16 biți permit o dinamică de 96 dB, iar 24 de biți sunt standardul de studio).
3. Numărul de canale: Mono (un singur canal de sunet) sau Stereo (două canale independente: stânga și dreapta).
Formate audio:
• Necomprimate (Lossless): WAV, AIFF — fidelitate maximă, dar fișiere foarte mari (aproximativ 10 MB per minut de audio stereo);
• Comprimate fără pierderi: FLAC — reduce dimensiunea cu aproximativ 50% fără a distruge niciun bit de informație;
• Comprimate cu pierderi (Lossy): MP3, AAC, OGG Vorbis — folosesc modele psihoacustice pentru a elimina frecvențele inaudibile pentru om, reducând fișierul de până la 10-12 ori (ex: bitrate de 128-320 kbps).
Aplicațiile de editare audio (Audacity) permit: decuparea zgomotului de fond (Noise Reduction), tăierea segmentelor de liniște, aplicarea de efecte de amplificare, egalizare și tranziții line de volum (Fade In la intrare și Fade Out la ieșire).
* Calitatea sunetului depinde de rata de eșantionare (ex: 44.1 kHz) și adâncimea de biți (16 sau 24 biți).
* Formatul WAV este necomprimat și fidel, în timp ce MP3 este comprimat cu pierderi calculate.
* Efectele Fade In (creștere treptată) și Fade Out (scădere treptată) evită pocniturile audio la început și final.
* Reducerea zgomotului (Noise Reduction) curăță fâșâitul de fond din înregistrările vocale.
= rată de eșantionare :: numărul de măsurători ale undei sonore realizate într-o secundă (ex: 44.100 Hz)
= bitrate audio :: cantitatea de date procesată pe secundă de un flux de sunet (ex: 320 kbps)
= Fade In / Fade Out :: tranziții sonore line de creștere sau descreștere a volumului audio
= psihoacustică :: știința care studiază percepția auditivă umană, stând la baza compresiei MP3
@ Ce rată de eșantionare este standardul internațional pentru calitatea de CD audio? :: 44.1 kHz (44.100 de mostre pe secundă).
@ Care este diferența de stocare între formatele WAV și MP3? :: WAV este necomprimat (fișiere mari), în timp ce MP3 este comprimat cu pierderi (fișiere de 10 ori mai mici).
@ Ce efect audio realizează intrarea lină a volumului unei melodii de la zero la nivel normal? :: Efectul de Fade In.
@ La ce folosește filtrarea de reducere a zgomotului (Noise Reduction) în Audacity? :: La eliminarea zgomotului static sau a fâșâitului microfonului dintr-o înregistrare.
? Numărul de măsurători ale undei de sunet efectuate într-o singură secundă se numește:
+ rată de eșantionare (Sampling Rate)
- rezoluție optică
- lățime de bandă
- volum de disc
! Rata de eșantionare dictează frecvența maximă ce poate fi reprodusă din semnal.
? Formatul de fișier audio comprimat utilizat pe scară largă pentru muzică pe internet este:
+ .mp3
- .bmp
- .docx
- .zip
! MP3 este cel mai celebru format audio comprimat din lume.
? Pentru a crea o încheiere armonioasă a unei piese audio prin scăderea lentă a volumului până la liniște completă, se aplică:
+ Fade Out
- Fade In
- Mute total brusc
- Overclocking
! Fade Out atenuează treptat volumul sonor la finalul melodiei.
? O înregistrare audio de tip „Stereo” se distinge de una „Mono” prin faptul că:
+ conține două canale de sunet independente (stânga și dreapta)
- conține doar zgomot alb
- nu se poate asculta la căști
- are o singură pistă mută
! Stereo oferă spațialitate prin separarea canalelor stâng și drept.

### tic11-05 | Imagine în mișcare, formatele video și montajul digital
Un fișier video este compus dintr-o succesiune rapidă de cadre statice (imagini/frame-uri) afișate la un interval scurt de timp, exploatând fenomenul de persistență a vederii pe retina umană pentru a crea iluzia mișcării continue.
Parametrii tehnici fundamentale ai producției video:
1. Rata de cadre pe secundă (FPS - Frames Per Second):
• 24 FPS — standardul tradițional al cinematografiei (oferă aspectul cald „cinematic”);
• 25 / 30 FPS — standardele televiziunii europene (PAL) și americane (NTSC);
• 60 FPS — standardul pentru transmisiuni sportive și jocuri video fluide.
2. Rezoluția video (numărul de pixeli pe orizontală și verticală):
• HD Ready: 1280 x 720 pixeli (720p);
• Full HD: 1920 x 1080 pixeli (1080p) — standardul cel mai răspândit pe internet;
• 4K UHD: 3840 x 2160 pixeli (2160p) — de 4 ori mai mulți pixeli decât Full HD.
3. Raportul de aspect (Aspect Ratio): raportul dintre lățime și înălțime. 16:9 este standardul panoramic pentru ecrane TV, monitoare și YouTube; 9:16 este formatul vertical optimizat pentru smartphone-uri (TikTok, YouTube Shorts, Instagram Reels).
4. Codecuri și containere:
• Containerul video (.mp4, .mkv, .avi) este cutia care împachetează pista video, pistele audio și subtitrările;
• Codecul (H.264 / AVC, H.265 / HEVC, AV1) este algoritmul care comprimă datele video uriașe pentru a putea fi transmise pe internet.
Etapele montajului video într-o aplicație de editare (CapCut, DaVinci Resolve, Premiere): importul materialelor brute, aranjarea pe axa cronologică (Timeline), tăierea cadrelor (Split / Trim), tranzițiile între secvențe, adăugarea de text și titluri, mixajul coloanei sonore și randarea/exportul final.
* Mișcarea video este creată de succesiunea rapidă de cadre afișate pe secundă (FPS).
* 1080p (Full HD) are rezoluția de 1920x1080 pixeli, iar formatul standard pe ecran este panoramic 16:9.
* H.264 este cel mai compatibil codec video modern integrat în containerul MP4.
* Montajul video pe axa cronologică (Timeline) combină secvențele filmate, tranzițiile și sunetul.
= FPS :: cadre pe secundă (Frames Per Second), indicând fluiditatea fluxului video
= codec video :: algoritm hardware sau software de compresie și decompresie a semnalului video
= rezoluție 1080p :: format video cu 1080 de linii orizontale având 1920 pixeli pe linie (Full HD)
= Timeline :: axa timpului din programele de montaj pe care se aliniază pistele video și audio
@ Ce rezoluție în pixeli are un videoclip Full HD (1080p)? :: 1920 x 1080 pixeli.
@ Ce măsoară valoarea FPS a unui fișier video? :: Numărul de cadre afișate într-o secundă (Frames Per Second).
@ Care este raportul de aspect standard pentru ecranele panoramice moderne și YouTube? :: Raportul 16:9.
@ Ce rol are un codec video (precum H.264)? :: Comprimă fluxul video masiv pentru a putea fi transmis și redat cursiv pe internet.
? Rata standard de cadre pe secundă utilizată în producțiile cinematografice clasice este de:
+ 24 FPS
- 1 FPS
- 500 FPS
- 10.000 FPS
! 24 de cadre pe secundă creează iluzia naturală de mișcare a cinematografului.
? Rezoluția video 4K UHD are o lățime de:
+ 3840 pixeli
- 640 pixeli
- 100 pixeli
- 1920 pixeli
! 4K oferă 3840 x 2160 pixeli, dublând rezoluția pe fiecare axă față de Full HD.
? Pe axa cronologică (Timeline) dintr-un editor video se așază:
+ pistele video, pistele de sunet și titlurile în ordinea derulării lor
- doar fișiere de text Word
- adresele IP ale utilizatorilor
- meniurile de BIOS
! Timeline-ul permite tăierea, potrivirea și sincronizarea precisă a imaginilor cu muzica.
? Formatul cel mai popular și universal compatibil pentru videoclipuri pe web este containerul:
+ .mp4 (cu codec H.264)
- .txt
- .wav
- .psd
! MP4 este redat nativ pe toate telefoanele, calculatoarele și televizoarele inteligente.

### tic11-06 | Principii de design vizual, compoziție și identitate grafică
Crearea materialelor promoționale, a afișelor școlare sau a interfețelor digitale cere aplicarea unor principii fundamentale de design grafic:
1. Compoziția și Ierarhia Vizuală: ochiul privitorului trebuie ghidat natural prin pagină în funcție de importanța informațiilor. Elementul cel mai important (titlul mare sau imaginea cheie) trebuie să aibă cea mai mare greutate vizuală. Regula treimilor (Rule of Thirds) împarte spațiul în 9 dreptunghiuri egale prin două linii orizontale și două verticale, recomandând plasarea punctelor de interes la intersecțiile acestor linii.
2. Spațiul alb (Negative / White Space): spațiul liber lăsat în mod deliberat între elementele grafice și blocuri de text. Spațiul alb nu este spațiu irosit, ci aerul care oferă respirație, claritate și eleganță compoziției, prevenind aglomerarea obositoare.
3. Teoria culorilor: culorile transmit emoții și stabilesc tonul comunicării. Roata culorilor permite construirea de scheme armonioase: culori complementare (aflate pe poziții diametral opuse: albastru-portocaliu, galben-violet, ce creează contrast puternic), culori analoage (alăturate pe roată, ce inspiră liniște) și culori monocromatice.
4. Tipografia: arta de a alege și combina fonturile.
• Fonturi Serif (cu mici tălpice decorative la capetele literelor, ex: Times New Roman, Georgia) — tradiționale, formale, excelente pentru cărți tipărite lungi;
• Fonturi Sans-Serif (fără tălpice, drepte și moderne, ex: Arial, Roboto, Open Sans) — ideale pentru ecrane digitale, oferind lizibilitate clară la orice mărime;
• Regula de aur a tipografiei: nu combinați mai mult de 2-3 familii de fonturi într-un singur material.
* Ierarhia vizuală conduce privirea cititorului de la elementul dominant către detaliile secundare.
* Spațiul alb (White Space) aerisește compoziția și crește senzația de profesionalism.
* Fonturile Sans-Serif (fără tălpice) sunt recomandate pentru lizibilitatea optimă pe ecrane digitale.
* Se recomandă utilizarea a maximum două familii de fonturi complementare într-o machetă.
= ierarhie vizuală :: ordonarea mărimii, grosimii și poziției elementelor pentru a ghida atenția privitorului
= White Space :: spațiul liber din jurul elementelor de design care conferă claritate vizuală
= font Sans-Serif :: categorie de fonturi moderne lipsite de tălpice la extremitățile literelor (ex: Arial)
= culori complementare :: nuanțe diametral opuse pe cercul cromatic ce produc un contrast viu
@ Ce recomandă Regula Treimilor în compoziția vizuală? :: Plasarea subiectului principal la intersecția liniilor imaginare care împart cadrul în treimi.
@ Ce rol are „spațiul alb” (White Space) într-un afiș sau o pagină web? :: Oferă lizibilitate, eleganță și împiedică aglomerarea sufocantă a textului.
@ De ce sunt preferate fonturile Sans-Serif pe ecranele telefoanelor și calculatoarelor? :: Deoarece liniile lor drepte și curate se citesc mult mai clar la rezoluțiile pixelilor de ecran.
@ Câte tipuri diferite de fonturi este indicat să combini pe un singur afiș promoțional? :: Maximum două sau trei familii de fonturi.
? Categoria de fonturi caracterizată prin linii drepte, fără tălpice la capete, ideală pentru ecrane este:
+ Sans-Serif
- Serif
- Gotice decorative

### tic11-07 | Etapele ciclului de viață al unui proiect digital și planificarea
Orice proiect digital de anvergură (crearea unui site web al școlii, dezvoltarea unei aplicații mobile sau organizarea unui eveniment online) presupune parcurgerea etapelor clasice ale ciclului de viață:
1. Inițierea: definirea scopului proiectului, a obiectivelor SMART (Specifice, Măsurabile, Atinse, Relevante, Încadrate în Timp), a publicului țintă și a rezultatelor așteptate (Deliverables).
2. Planificarea: descompunerea proiectului în activități concrete (Work Breakdown Structure - WBS), stabilirea dependențelor dintre sarcini (ex: nu poți programa baza de date înainte de a avea specificațiile), alocarea responsabilităților pe membri și estimarea bugetului și a termenelor limită.
Instrumentul clasic de planificare temporală este Diagrama Gantt — o reprezentare grafică cu bare orizontale care arată data de început, durata și data de finalizare a fiecărei sarcini, precum și sarcinile care se desfășoară în paralel.
3. Execuția și dezvoltarea: crearea propriu-zisă a conținutului, a designului și scrierea codului de către echipă.
4. Monitorizarea și controlul: verificarea ritmului de lucru față de graficul Gantt și ajustarea resurselor.
5. Încheierea: predarea proiectului, instruirea utilizatorilor și analiza lecțiilor învățate (post-mortem).
* Etapele fundamentale ale unui proiect sunt: inițiere, planificare, execuție, monitorizare și finalizare.
* Obiectivele SMART garantează claritatea și măsurabilitatea rezultatelor dorite.
* Diagrama Gantt ilustrează vizual calendarul sarcinilor și dependențele dintre etape.
* Structura WBS descompune proiectul mare în livrabile mici și ușor de repartizat membrilor echipei.

### tic11-08 | Testarea produselor digitale, feedback-ul și metodologii agile
Niciun produs software sau material digital nu se lansează public fără o etapă riguroasă de testare și asigurare a calității (QA - Quality Assurance):
1. Tipuri de testare în dezvoltarea web și digitală:
• Testarea funcțională: verificarea dacă toate butoanele, formularele, legăturile și meniurile funcționează conform specificațiilor;
• Testarea cross-browser: verificarea afișării corecte și a comportamentului pe toate marile browsere (Chrome, Firefox, Safari, Edge);

• Testarea de performanță și securitate: măsurarea timpilor de răspuns și testarea rezistenței la intrări malițioase în formulare.
2. Ciclul de feedback și îmbunătățire:
Colectarea impresiilor de la utilizatori reali (User Testing) evidențiază probleme de uzabilitate (UX) pe care dezvoltatorii nu le-au observat.

La finalul fiecărui sprint se livrează o versiune funcțională testabilă, permițând adaptarea rapidă la schimbările de cerințe ale clientului.
* Testarea cross-browser garantează afișarea identică a site-ului pe toate browserele.
* Designul receptiv (Responsive) asigură adaptarea fluentă a paginii pe telefoane și calculatoare.
* Metodologia Agile lucrează în iterații scurte (sprinturi) cu livrări frecvente de software util.
* Feedback-ul colectat de la utilizatorii reali ghidează corectarea dificultăților de utilizare (UX).

## 2 | tic11-c4 | Dezvoltare web practică: HTML5 și CSS3 de bază
### tic11-10 | Structura schelet a unei pagini HTML5 și elemente semantice
O pagină web validă respectă o structură arborescentă strictă definită de limbajul HTML5. Fișierul se salvează obligatoriu cu extensia `.html` (de regulă `index.html` pentru pagina principală de pornire a oricărui site).
Structura de bază minimală a unui document HTML5:
```html
<!DOCTYPE html>
<html lang="ro">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Titlul Paginii în Fila Browserului</title>
</head>
<body>
    <!-- Conținutul vizibil pe ecran se scrie aici -->
</body>
</html>
```
Elementele structurale principale:
1. `<!DOCTYPE html>`: declară versiunea modernă HTML5 și forțează browserul să randeze în modul standard corect;
2. `<html>`: elementul rădăcină (root) care înglobează întregul document;
3. `<head>`: conține metadate (informații despre pagină care nu se afișează direct în corpul paginii): codificarea caracterelor (`UTF-8` pentru diacritice românești), setările pentru dispozitive mobile (`viewport`), legătura către fișierul extern de stiluri CSS și textul din fila browserului (`<title>`);
4. `<body>`: conține tot ceea ce vede și cu ce interacționează utilizatorul pe ecran;
5. Elemente de conținut și semantice:
• Titluri ierarhice: `<h1>` (titlul principal al paginii, unic), `<h2>`, `<h3>` până la `<h6>`;
• Paragrafe: tagul `<p>`;
• Întrerupere de rând forțată: tagul vid `<br>`;
• Linie orizontală despărțitoare: tagul vid `<hr>`;
• Text evidențiat: `<strong>` (text îngroșat semantic) și `<em>` (text cursiv cu accent).
* Declarația `<!DOCTYPE html>` instruiește browserul că documentul folosește standardul HTML5.
* În interiorul `<head>` se plasează metadatele, setarea UTF-8 și legăturile către stiluri.
* Tot conținutul vizibil pe ecranul paginii se scrie în interiorul tagului `<body>`.
* Ierarhia titlurilor pornește de la `<h1>` (cel mai important) până la `<h6>` (cel mai mărunt).
= tag (etichetă HTML) :: element de sintaxă încadrat între paranteze unghiulare (ex: `<p>` și `</p>`)
= metadată :: informație ce descrie datele paginii (stocată în secțiunea `<head>`)
= UTF-8 :: codificare universală ce asigură afișarea corectă a literelor românești cu diacritice
= semantică HTML5 :: utilizarea etichetelor care reflectă semnificația logică a conținutului
@ Ce declară prima linie `<!DOCTYPE html>` dintr-un document web? :: Declară tipul documentului ca fiind scris în standardul modern HTML5.
@ Unde se plasează tagul `<title>` și ce rol are el? :: Se plasează în secțiunea `<head>` și stabilește textul afișat în fila sau tab-ul browserului.
@ Care este tagul corect pentru introducerea unui paragraf simplu de text în HTML? :: Tagul `<p>` închis cu `</p>`.
@ Ce tag HTML produce o trecere la rând nou fără a crea un paragraf complet nou? :: Tagul vid `<br>`.
? Zona din documentul HTML care conține informații despre pagină, stiluri și titlul filei browserului este:
+ `<head>`
- `<body>`
- `<footer>`
- `<nav>`
! În `<head>` stau metadatele, în timp ce în `<body>` stă conținutul vizual.
? Tagul HTML dedicat celui mai important titlu dintr-o pagină web este:
+ `<h1>`
- `<h6>`
- `<header>`
- `<title>`
! `<h1>` este titlul de rang maxim pe pagină.
? Pentru a scrie un text îngroșat cu valoare semantică de importanță, se folosește eticheta:
+ `<strong>`
- `<italic>`
- `<u>`
- `<font size="large">`
! `<strong>` marchează textul cu importanță ridicată și îl afișează îngroșat (Bold).
? Atributul din tagul `<meta>` care garantează afișarea literelor ă, î, ș, ț este:
+ charset="UTF-8"
- language="Romanian"
- font="Arial"
- mode="diacritics"
! Codificarea UTF-8 acoperă întreg setul de caractere universale.

### tic11-11 | Formatarea stilistică cu CSS: reguli, selectori și Box Model
CSS (Cascading Style Sheets) oferă control deplin asupra aspectului vizual al paginilor web.
Sintaxa fundamentală a unei reguli CSS:
```css
selector {
    proprietate: valoare;
    proprietate: valoare;
}
```
1. Modalități de includere a stilurilor CSS:
• CSS Extern (recomandat profesional): un fișier separat `.css` legat în `<head>` prin linia:
`<link rel="stylesheet" href="stil.css">`
• CSS Intern: scris direct în secțiunea `<head>` a paginii în interiorul unui bloc `<style>...</style>`;
• CSS Inline: scris direct pe tag prin atributul `style="color: blue;"` (de evitat în proiecte mari).
2. Selectori fundamentale în CSS:
• Selector de tip element (tag): `p { color: #333333; }` — aplică regula tuturor paragrafelor;
• Selector de clasă (precedat de punct): `.buton-salvare { background-color: green; }` — aplicat oricărui element care conține `class="buton-salvare"`; o clasă poate fi reutilizată pe zeci de elemente;
• Selector de identificator unic (precedat de diez): `#meniu-principal { width: 100%; }` — aplicat elementului cu `id="meniu-principal"`; id-ul trebuie să fie unic pe pagină.
3. Modelul cutiei (CSS Box Model):
Fiecare element HTML este tratat de browser ca o cutie dreptunghiulară compusă din 4 straturi succesive din interior spre exterior:
• Conținutul (Content): textul sau imaginea propriu-zisă;
• Spațiul interior (Padding): spațiul liber dintre conținut și chenar;
• Chenarul (Border): linia de contur ce înconjoară elementul;
• Marginea exterioară (Margin): spațiul liber de respirație dintre chenar și elementele vecine din pagină.
* Fișierul CSS extern se leagă în secțiunea `<head>` cu eticheta `<link rel="stylesheet">`.
* Selectorul de clasă începe cu punct (.nume), iar cel de identificator cu diez (#nume).
* Box Model este format din Conținut, Padding (spațiu interior), Border (chenar) și Margin (margine exterioară).
* Proprietățile fundamentale de text sunt: `color`, `font-size`, `font-family` și `text-align`.
= selector CSS :: șablon ce indică browserului căror elemente HTML li se aplică regula de stil
= CSS extern :: fișier independent de stiluri (.css) partajat de toate paginile site-ului
= Box Model :: conceptul structural prin care fiecare element este format din conținut, padding, border și margin
= Padding :: distanța interioară dintre text și marginea chenarului cutiei
@ Cu ce caracter începe obligatoriu un selector de clasă în CSS? :: Cu punctul (ex: `.evidentiat`).
@ Cu ce simbol se prefixează un selector de identificator (id) în CSS? :: Cu simbolul diez (ex: `#antet`).
@ Care este diferența dintre Margin și Padding în CSS Box Model? :: Padding este spațiul interior (dintre conținut și chenar), iar Margin este spațiul exterior (dintre chenar și elementele vecine).
@ Cum legi un fișier extern de stiluri numit `stil.css` la o pagină HTML? :: Prin `<link rel="stylesheet" href="stil.css">` plasat în interiorul etichetei `<head>`.
? Selectorul CSS care aplică stilul elementului unic ce are atributul `id="sigla"` este:
+ #sigla
- .sigla
- $sigla
- sigla()
! Simbolul diez (#) indică întotdeauna un identificator unic (ID).
? Proprietatea CSS utilizată pentru a schimba culoarea textului dintr-un paragraf este:
+ color
- background-color
- text-color
- font-style
! Proprietatea `color` dictează nuanța literelor, iar `background-color` nuanța fundalului.
? În cadrul CSS Box Model, stratul transparent situat între chenar (border) și elementele vecine este:
+ Margin (Marginea exterioară)
- Padding (Căptușeala)
- Content (Conținutul)
- Title (Titlul)
! Marginea exterioară (Margin) împinge elementele din jur pentru a crea spațiu liber.
? În fișierul CSS, o clasă numită `rezumat` se definește corect prin:
+ `.rezumat { font-size: 14px; }`
- `rezumat { font-size: 14px; }`
- `#rezumat { font-size: 14px; }`
- `<rezumat> { font-size: 14px; }`
! Punctul din fața numelui marchează o clasă reutilizabilă în CSS.

### tic11-12 | Legături hipertext, imagini și tabele în limbajul HTML
Interactivitatea și bogăția vizuală a paginilor web depind de tagurile fundamentale de conectare și reprezentare a datelor:
1. Legături hipertext (Hyperlinks): se creează cu tagul ancorei `<a>`:
`<a href="adresa_destinatie" target="_blank">Textul pe care dai clic</a>`
• Atributul `href` (hypertext reference): specifică URL-ul paginii spre care trimite linkul;
• Atributul `target="_blank"`: forțează deschiderea linkului într-o filă nouă a browserului;
• Legături locale (relative): ex: `href="contact.html"` sau către o ancoră internă din aceeași pagină: `href="#capitol3"`.
2. Inserarea imaginilor: se realizează cu eticheta vidă `<img>`:
`<img src="imagini/peisaj.jpg" alt="Vedere panoramică din Ceahlău" width="600" height="400">`
• Atributul `src` (source): calea către fișierul imagine;
• Atributul `alt`: textul alternativ descriptiv (esențial pentru accesibilitate);
• Atributele `width` și `height`: dimensiunile de afișare în pixeli.
3. Tabele în HTML: organizează datele în linii și celule:
• `<table>`: containerul principal al tabelului;
• `<tr>` (table row): definește un rând orizontal;

## 2 | tic11-c5 | Multimedia avansată și proiecte web
### tic11-13 | Grafică digitală avansată: straturi, măști și optimizare pentru web
Pregătirea resurselor grafice pentru interfețe web solicită stăpânirea tehnicilor de compoziție grafică:
1. Măști de strat (Layer Masks):
În loc să ștergi definitiv o porțiune dintr-o fotografie cu guma (Eraser) — acțiune distructivă ce nu mai poate fi remediată —, programele profesionale (Photoshop, GIMP) folosesc măștile de strat. Masca funcționează pe bază de niveluri de gri: albul păstrează vizibilitatea completă a pixelilor, negrul ascunde complet zona (o face transparentă), iar nuanțele de gri creează transparențe treptate. Astfel, orice decupaj poate fi corectat oricând prin simpla vopsire cu alb a zonei ascunse.
2. Canale alfa și decuparea pe transparență:
Formatul PNG suportă canal alfa pe 8 biți (256 niveluri de transparență), permițând decuparea fină a părului sau a obiectelor de sticlă ce se așază impecabil peste orice culoare de fundal a paginii web, fără margini albe zimțate.
3. Formatele moderne de grafică pentru web:
• SVG (Scalable Vector Graphics): cod XML pur pentru icoane și logouri, ocupând câțiva Kilobytes și randat perfect ascuțit pe orice ecran Retina sau 4K;
• WebP: oferă compresie superioară cu 25-35% față de clasicul JPEG la aceeași calitate vizuală;
• AVIF: cea mai nouă tehnologie de compresie a imaginilor derivată din codecul video AV1.
Optimizarea dimensiunii fișierelor grafice este o cerință majoră: imaginile brute de la camerele foto (care au adesea 15-30 MB) trebuie redimensionate la lățimea maximă necesară pe ecran (ex: 1920 px) și comprimate la 80% calitate, ajungând la sub 200-300 KB pentru a nu bloca navigarea pe mobil.
* Măștile de strat permit ascunderea reversibilă și nedistructivă a zonelor dintr-o imagine.
* Canalul alfa pe 8 biți asigură transparențe fine și tranziții naturale peste orice fundal.
* Formatul vectorial SVG este descris prin cod XML și este scalabil infinit fără consum mare de memorie.
* Imaginile pentru web trebuie redimensionate și comprimate la sub 300 KB pentru încărcare rapidă.

### tic11-14 | Sunet și video integrate în HTML5: elementele audio și video
Înainte de HTML5, redarea conținutului multimedia pe web impunea instalarea de pluginuri terțe nesigure și consumatoare de baterie (precum Adobe Flash). Standardul HTML5 a revoluționat industria prin introducerea elementelor multimedia native `<audio>` și `<video>`:
1. Eticheta `<audio>` pentru fișiere de sunet:
```html
<audio controls preload="auto">
    <source src="muzica/podcast.mp3" type="audio/mpeg">
    <source src="muzica/podcast.ogg" type="audio/ogg">
    Browserul dumneavoastră nu suportă redarea audio HTML5.
</audio>
```
Atribute esențiale:
• `controls`: afișează bara standard a browserului cu butoane de Play/Pauză, volum și progres;
• `autoplay`: pornește automat redarea (adesea blocat de browsere dacă sunetul nu este pe mut);
• `loop`: reia redarea de la început în mod continuu;
• `muted`: pornește sunetul oprit.
2. Eticheta `<video>` pentru filme și animații:
```html
<video width="800" height="450" controls poster="imagini/coperta.jpg">
    <source src="video/lectie.mp4" type="video/mp4">
    <source src="video/lectie.webm" type="video/webm">
    Mesaj de rezervă pentru browsere învechite.
</video>
```
Atribute suplimentare specifice video:
• `poster`: specifică o imagine statică afișată ca și copertă înainte de apăsarea butonului Play;
• `width` și `height`: stabilesc dimensiunea exactă a casetei video pentru a preveni saltul vizual al paginii în timpul încărcării;
Tagul `<source>` din interior permite specificarea mai multor formate alternative; browserul îl va alege și reda automat pe primul pe care îl suportă nativ.
* HTML5 redă audio și video direct în browser fără a necesita pluginuri nesigure precum Flash.
* Atributul `controls` este obligatoriu pentru a oferi utilizatorului butoanele de Play și volum.
* Atributul `poster` afișează o imagine de copertă peste caseta video înainte de pornire.
* Se pot include mai multe taguri `<source>` pentru a asigura compatibilitatea pe orice sistem.

= `<video>` :: element nativ HTML5 pentru afișarea și redarea fluxurilor video
= atributul controls :: afișează comenzile native de redare (Play, Pause, volum, bară de derulare)
= atributul poster :: imaginea de previzualizare afișată înaintea pornirii unui clip video

### tic11-16 | Securitate web, prevenirea atacurilor și etica platformelor online
Securitatea aplicațiilor web este o necesitate critică, serverele fiind expuse permanent tentativelor de intruziune automatizate:
1. Amenințări cibernetice comune pe web:
• Injecția SQL (SQL Injection): introducerea de comenzi malițioase de baze de date în câmpurile unui formular web nesecurizat pentru a fura parole sau a șterge întreaga bază de date; protecția impune utilizarea interogărilor parametrizate (Prepared Statements);
• Cross-Site Scripting (XSS): injectarea de scripturi malițioase JavaScript în paginile vizualizate de alți utilizatori (ex: într-un comentariu pe forum), având ca scop furtul cookie-urilor de sesiune;
• Stocarea nesigură a parolelor: este strict interzisă păstrarea parolelor în clar (Plain Text) în bazele de date; parolele trebuie trecute printr-o funcție criptografică de dispersie (Hashing: bcrypt, Argon2, SHA-256) cu adăugarea unei valori aleatorii de securitate (Salt).
2. Etica digitală și responsabilitatea platformelor:
• Algoritmii de recomandare ai rețelelor sociale tind să promoveze conținut senzaționalist, polarizant și știri false (Clickbait) pentru a maximiza timpul petrecut pe ecran;
• Bulele informaționale (Echo Chambers) izolează utilizatorii în grupuri ce împărtășesc aceleași opinii, reducând gândirea critică și dialogul democratic;
• Respectarea vieții private a utilizatorilor și colectarea exclusivă a datelor strict necesare (Data Minimization conform GDPR) constituie o obligație juridică și etică a oricărui dezvoltator web.
* Parolele utilizatorilor nu se stochează niciodată în clar, ci exclusiv sub formă de hash criptografic.
* Injecția SQL exploatează formularele nevalidate pentru a manipula baza de date de pe server.
* Atacurile XSS încearcă să execute cod JavaScript malițios în browserul altor vizitatori.
* Principiul minimizării datelor din GDPR impune colectarea doar a informațiilor strict necesare.
= SQL Injection :: atac cibernetic prin care se injectează comenzi SQL prin intermediul formularelor web
= hash criptografic :: transformare ireversibilă a unui text într-un șir de caractere de lungime fixă (ex: SHA-256)
= XSS :: atac ce injectează scripturi malițioase în paginile web vizitate de alte persoane
= bulă informațională :: mediu digital închis în care un utilizator este expus doar opiniilor care îi confirmă convingerile

? Formatul de imagine vectorială descris prin cod XML utilizat nativ pe web este:
+ .svg
- .jpg
- .bmp
- .mp3
! SVG este formatul vectorial standard pentru web.
? Pentru a reda un fișier video nativ în HTML5 cu butoane vizibile de control, se folosește:
+ `<video controls>`
- `<movie play>`
- `<media auto>`
- `<film>`
! `<video controls>` este tagul nativ oficial HTML5.
? Imaginea statică de copertă afișată peste un videoclip HTML5 înainte de apăsarea Play se specifică prin:
+ poster
- cover
- screen
- image
! Atributul poster stabilește imaginea de previzualizare.
? Sistemul universal de control al versiunilor utilizat de echipele software se numește:
+ Git
- Word
- Excel
- Access
! Git gestionează versiunile și colaborarea pe cod.
? Salvarea corectă a parolelor într-o bază de date impune utilizarea:
+ unei funcții de hash criptografic cu salt
- textului simplu necriptat
- fișierelor PDF cu parolă
- capturilor de ecran
! Hash-ul protejează parola împotriva furtului de date.
? Atacul cibernetic ce exploatează câmpurile unui formular web pentru a introduce comenzi neautorizate în baza de date se numește:
+ SQL Injection
- Defragmentare
- Paginare automată
- Rețea LAN
! SQL Injection este una dintre cele mai critice vulnerabilități web.
